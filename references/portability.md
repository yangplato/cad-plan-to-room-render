# 在其他 Agent 与聊天平台中使用

这是开放的资料、Prompt 与核验流程，不依赖 ChatGPT 的隐含会话或某个工具名。目标平台能做什么，以本次真实工具和界面为准；不能因为叫豆包、Kimi 或 Work Buddy 就预设有 CAD 或生图能力。

| 当前能力 | 执行方式与交付 |
|---|---|
| 可读 Skill 文件夹、看图、执行代码、携图生图 | 原生使用 SKILL.md，按需加载阶段文档；结构化工具可选。 |
| 可看图和携图生图，无终端/原生Skill | 复制下方入口，附当前阶段文档、图纸与参考图；用消息保存确认信息，逐步生成与自检。 |
| 可看图，不能生图 | 识别/核对并交付完整 Prompt、实际附件顺序、待执行步骤；状态为尚未生成。 |
| 不能直接读DWG，但能看图片 | 使用CAD导出的PNG/PDF；需要原生几何再换有解析工具的环境，不伪造转换结果。 |
| 能生成但不能查看输出 | 只记录生成完成，视觉核验待具备看图能力的一方处理，不能判定质量通过。 |

没有原生 Skill 导入功能也能复用 B/C 提示词与核验。标准包内相对路径供文件型 Agent 使用；聊天上传时，逐个上传真实图片及当前阶段文字，确认平台能读出内容。不要把本机路径当作上传，不依赖压缩包会自动解包、会话会永久记住附件或会执行脚本。

## 可复制入口

```text
请按附带的“平面→彩平→空间效果图”流程处理这次住宅资料。先检查你实际能读哪些文件、是否可以携带参考图生图和查看生成图。只执行我请求的阶段，已有确认资料直接承接。
原平面确定墙门窗、房间连通以及家具和洁具的类别、数量、位置、朝向与占位；未说明的墙统一通高。占位模型不指定家具款式，彩平阶段按风格选款，效果图阶段继承本套已选设计。缺失立面可以合理补全，但不改布局。
按实际附件顺序区分布局图、质感样张、风格参考与本套设计图；不能从另一案例复制空间。先核对整理图，再做彩平；效果图的摄影构图在正确空间里完成。逐张检查布局、使用合理性和摄影材质，重大错误回到依据重制。
这次任务：〔阶段、风格、需要的房间〕。附带的是本阶段的详细规则与实际图片。不能执行的步骤明确交付待执行资料，不假装生成或验收。
```

## 每阶段只传必要内容

- A：原图＋本图已知信息＋prepare-plan.md。有原生CAD能力再使用scene-contract.md；不要上传质量样图来替代原图。
- B：核实干净平面＋本图确认信息＋color-plan.md中的母版＋style-modules.md的一个模块＋适用彩平质量样张。输入上限紧张时保留结构图优先，缩减无关参考。
- C：当前平面（覆盖可见邻室）＋本套已选彩平＋room-render.md模板和本房设计事实；有可靠占位提示/摄影参考再附。不要再次加入B重新选型的段落。

换平台时带走当前图、个案事实、已选设计、实际Prompt与核验状态，不靠“沿用上个聊天”。先用一张彩平和一个房间验证布局/材质/款式传递，再扩大数量。迁移的是方法和材料，不承诺不同模型输出相同像素或稳定相同品质。
