# 住宅十风格模块

这是可离线执行的设计知识与 B 阶段风格 Prompt。家具构造、材料关系、房间适配和检查点已写在正文；**普通生图只读所选模块，不加载研究来源，也不需要访问外链**。不把研究中的品牌名写入 Prompt，不要求复刻研究产品或上传品牌图。

可选维护入口：[风格研究依据与转译边界](../docs/style-research.md)，仅在维护或复核来源时读取。

名称沿用项目采用的业之峰十风格分类，不是品牌官方 Prompt、官方合作或唯一风格标准。下列配方是基于历史及产品构造证据作出的当代住宅设计选择；“奶油风”“意式轻奢”等商业名称、宋意转译与历史复原应分清。正文保留可执行设计与边界，来源事实在维护附录中独立保存。

## 执行方式

1. 读取所选风格的完整设计卡；将其 **B 风格模块**与通用母版、核对后的个案信息组合。无需加载其他九种，也不要把全部风格同时塞进提示词。用户未选风格时，用文末对照表给出可理解的选择，不自选风格开画。
2. 只应用于输入实际存在的物件。原图圆桌仍为圆桌，方桌仍保留已确认的基本形状；已有 L 形或组合沙发保留组合，单件不改套几。未指定产品时，可在占位包络内调整圆角、厚薄、扶手、框架和支撑；不得改变类别、数量、朝向、坐卧人数或通道。
3. CAD 符号和体块说明“这里有什么、占多大”，不指定产品款式。用户已指定产品时优先保留，不为追求风格标签换掉。风格可通过其他未锁定物件与饰面实现；有明显冲突时说明取舍，不能把整套方案暗中改掉。
4. B 生成后记录实际选型：沙发/椅的框架与软包、桌形与支撑、床头、柜门、各房间地墙材料、关键点色。**C 继承这份选型与确认彩平，不再执行 B 的“重新选型”。**从本文件取用 C 的房间适配建议时，也不得随机换款。
5. 下文“墙面”均指室内立面，墙体切面仍统一按母版；衣柜抽象剖切、洗衣机平顶、洁具类别、默认通高墙等通用表达不被风格覆盖。天花是后续空间图的延续设定，彩平移除顶盖时不画天花；移除顶盖也不意味光能从整个屋顶照入。
6. 风格不改变窗口朝向和采光事实，不给整图套某种滤镜。墙地、织物、木、石、皮革要有不同粗糙度及真实尺度，软垫要有承重和接触阴影。原资料已锁定材料时保留；以下地墙方案只填补未确定部分。台面小陈设允许变化，大件与柜体功能不变。
7. B的光源开关遵守母版及本案明确要求；风格卡中的室内灯、天花和立面建议用于后续空间设计，不自动启用彩平内灯或覆盖日间自然光设置。

## 共享落地规则

- **保持形状的适配：**圆桌使用相应风格的圆台面、原范围内的支脚；方桌仅在允许范围内作圆钝角或倒边。窄椅不能硬塞宽包裹椅，大曲背改成同语汇的紧凑弧背；靠功能尺度与构造适配，不整体缩小家具逃避碰撞。
- **材料有做法：**木材交代板宽、拼缝、纹理方向与自然色差；石面交代纹理尺度、边缘厚度和哑光/微反射；织物区分平织、绒圈、细绒和皮革。不要把所有表面贴成同一种均匀纹理。下列石木名称是视觉设计表达，不能冒充采购型号或性能证明。
- **小房间有取舍：**少量辨识度高的构造比装满符号更有效。卧室优先床头、柜门、床品和地面关系，不扩大床或添床尾凳；厨卫优先柜门、台面、砖石与五金，不能照搬客厅地毯、裸藤或软包。
- **不以布景改方案：**不为风格新增壁炉、屏风、岛台、茶台、吊椅、大植物或门洞。原图未确定的小灯具及墙面装饰可合理设计，但不遮挡窗门、夸大层高或侵入通道。灯具呈现真实发光和反射，不用成排光带掩饰材质粗糙。

## 01 · 当代新中式

以清楚的中国木作语汇与现代软坐感并置。重点在木框、弧搭脑、软垫之间的构造，而非传统纹样数量。

### 离线设计卡

| 维度 | 可执行设定 |
|---|---|
| 家具构造 | 沙发深木细边框、窄木扶手、低直靠背，亚麻垫从木框中独立出来。单椅用轻巧弧形搭脑和细扶手；餐椅沿用弧木靠背。桌沿薄、内退木腿，木框可嵌细纹石面。床头为矩形木框嵌素软靠。固定柜以平板/窄框板门承接木作秩序，保留实际封闭功能。 |
| 地、墙、天花 | 公共区暖灰细石面，卧室中明度烟熏木；木纹按板缝走向展开。米白细灰泥室内墙面，局部木面有清楚收边。天花保持轻薄暖白，不凭风格添加梁架、藻井或结构。 |
| 配色与光照 | 米灰与暖白作大面积背景，深胡桃木承担结构轮廓，墨灰石面形成少量重心；暗铜只作小连接。原窗日光揭示木框与垫间阴影，避免红金滤镜和通体棕黑。 |
| 软装与使用 | 素麻、细羊毛、素陶和墨色器皿为主。已有桌面用低矮器皿或少量枝叶，构成疏密，保留桌面用途；不把柜顶自动变成陈列台。 |
| 俯视辨识 | 深木框与浅垫分离、椅背的弧形木线、薄桌沿、床外露木边。轮廓区别应在白底彩平缩小后仍可辨认。 |
| 房间适配 | 客餐用木框/石面对比；卧室减少硬石与深色面积，木床头和素床品延续同一语汇；厨卫用暖灰砖石、平整木色门与小暗铜五金，不新增格栅隔断。 |
| 邻近风格与误读 | 相较宋式，本路线允许更明显的现代软包与木石对比；相较意式，木构与弧搭脑更可读。避免宫廷红金、龙凤雕花、密集回纹、全套硬榻及大量假博古架。 |

### B 风格模块

```text
在原家具类别、数量、位置、方向、座位关系和可用包络内做当代新中式选型，保留原沙发组合与桌面的圆/方形态。以清楚木作结合现代软坐感：沙发采用深胡桃木细边框、窄木扶手、低直靠背和独立米灰亚麻软垫，垫面有轻微承重凹陷、细包边，木框与垫之间有真实阴影。单椅为当代化弧形木搭脑、细扶手、独立软坐面和轻直腿；餐椅使用同一弧木语汇，不画成厚方软包。餐桌与茶几沿原形状采用薄木边、内退木腿，台面为低反光细纹石与木框的清楚交接，不改成巨石块。床为低木框、矩形木框嵌亚麻软靠，独立床垫与外露木边可辨；床品用棉麻自然褶皱。固定柜保持原封闭功能，以胡桃木平板或窄框门、细小暗铜拉手表达，不变成博古架；衣柜彩平仍使用通用抽象剖切。公共区暖灰细石面、卧室中明度烟熏木，木板有自然色差和错缝；厨卫用低反光暖灰砖石。室内立面为米白细灰泥，局部木面收边清楚，天花简洁暖白，墙体切面遵循母版。米灰与暖白作背景，深木承担轮廓，墨灰石面作局部重心，暗铜少量点到为止。日光只从原有窗口进入，木框、亚麻垫、石面有不同反射和连续明暗。既有桌面少量素陶、墨色器皿和枝叶，保留使用面积。俯视要读出弧木椅背、木框与软垫、薄桌沿及木床边，不用龙凤雕花、宫廷红金、满墙回纹、厚重仿古套装，不添加屏风或主要家具。
```

## 02 · 宋式美学

本模块是宋意的当代住宅转译，选取线性木构、案面秩序、素织物及温润釉器的关系；不是宋代住宅考古复原。现代沙发、床垫和满墙柜按现代使用设计。

### 离线设计卡

| 维度 | 可执行设定 |
|---|---|
| 家具构造 | 沙发低直靠、窄水平木扶手、清楚茶褐底框与素麻分体垫，有榻感但保持软坐舒适。单椅窄横搭脑、分离扶手和细直腿。桌面薄而端正、内退直腿和横枨；床低木框、直床头嵌素靠；柜为干净框板门，非开放博古格。 |
| 地、墙、天花 | 中明度茶褐木地板和低反光暖灰湿区砖石；微暖白/淡灰泥墙，与茶褐框架形成清楚层次。简洁浅色天花，不虚构宋代梁架、斗拱或照搬寺庙。 |
| 配色与光照 | 米白与微暖灰为背景，茶褐木为主结构，黑褐漆面为少量深色面，青瓷绿作小焦点。原窗漫射日光有方向，釉面是柔和局部高光，木和麻保持低反光，暗面不能糊黑。 |
| 软装与使用 | 素棉麻床品、细平织地毯；在已有台面用少量青瓷、白瓷或黑釉器，尺寸适合日常使用。陈设有留空，不自动添茶席、文房满案、屏风或书法墙。 |
| 俯视辨识 | 水平窄木扶手与分离素垫、黑褐薄桌面、茶褐木床头和少量青瓷点色；依靠构造与材质关系，不靠写“宋”字或一件道具。 |
| 房间适配 | 客餐强调木框与案面；卧室用轻直木床头和素床品，保留现代床垫及柜门；厨卫用暖灰石砖、细木色门与普通现代洁具，不把卫生间做成古代场景。 |
| 邻近风格与误读 | 比当代新中式减少大纹石材、金属与厚软包，强调木构和素面器物；与北欧/日式的差别在茶褐/黑褐关系而非全浅木白色。不能把明清官帽椅称为宋代原型；禁宫廷雕花、日式障子、榻榻米和后世金缮的自动套用。 |

### B 风格模块

```text
在已确认的原类别、数量、位置、朝向、座位关系和占位内作宋式美学的当代住宅转译，保留沙发组合与餐桌圆/方形态。以茶褐线性木构、黑褐案面、素麻和温润青瓷建立关系。沙发是有榻感的现代木框软垫家具：低直靠背、窄水平木扶手、连续而轻巧的茶褐底框，米白亚麻坐垫与薄靠垫相互分离，有真实厚度、承重和边缘缝线，不是硬木板。单椅用窄横搭脑、分离木扶手、细直腿和素软坐面，不套用高大仿古官帽椅。餐桌与茶几按原圆或方轮廓做薄黑褐或茶褐面、内退稳定木腿与适合形状的横枨，不加雕刻；餐椅延续轻木框和素坐面。床为低木框、直木床头嵌素麻软靠，独立床垫，米白棉麻床品配烟灰或灰绿薄毯，自然重力褶皱清楚。固定柜采用干净框板木门和小拉手，保留原封闭功能，彩平衣柜执行统一抽象剖切。地面为中明度茶褐木板，有自然纹理、板缝和轻微色差；厨卫为低反光暖灰砖石。室内墙面微暖白细灰泥、天花简洁浅色，墙体剖面遵守母版，不画仿古梁架。米白背景、茶褐结构、黑褐小面积桌面和少量青瓷色有明暗层次。原窗日光形成柔和方向性，木与麻哑光，釉器保留柔和局部反射。既有台面仅放少量青瓷、白瓷或黑釉器与枝叶，保留功能面积。俯视读出线性框架、素垫、薄案面，不做全浅木全白、宫廷红金、密格栅、日式障子、榻榻米，不新增茶台、屏风或主要家具。
```

## 03 · 奶油风

当代住宅中柔和连续曲线与浅色多材质的组合。这是当代商业风格的设计组合，不假称历史流派或品牌官方分类。软不是模糊，圆不是没有受力，浅色不是把所有材质变成同一块米色。

### 离线设计卡

| 维度 | 可执行设定 |
|---|---|
| 家具构造 | 沙发在原组合中采用低连续弧背、大圆角扶手、宽软垫与内藏短脚。单椅马蹄/椭圆包裹靠背，座面独立下沉。桌面保留原基本形状，边缘圆钝、支撑内退，餐椅圆角软包弧背。床为圆角软头与薄软床围；柜保持直正平板，局部小圆角收口。 |
| 地、墙、天花 | 公共区象牙细砂石感或哑光砖，卧室浅橡木有板缝；细灰泥室内墙面和暖白平顶。圆角只落在家具与细收口，不把房间改成拱洞、曲墙和降层高穹顶。 |
| 配色与光照 | 奶油白作明亮底色，燕麦/浅杏作软包，浅木增加温度，少量自然灰稳定阴影。通过反射率与明度区别材质，不靠统一黄滤镜；软侧光勾出曲率，保留灰度层次。 |
| 软装与使用 | 细绒圈、细羊毛与棉麻分工，不把所有家具都做成夸张粗粒绒。已有桌面浅陶与少量透明玻璃；地毯边缘、厚度和纤维可读，不用失焦制造柔软。 |
| 俯视辨识 | 沙发弧背/圆角扶手，单椅包裹轮廓与下沉坐面，圆钝浅石台面、软床头；有清楚的物件边界与接触阴影。 |
| 房间适配 | 小客厅控制扶手厚度，不挤掉坐面；卧室圆角床头不延伸覆盖床头柜；厨卫使用浅哑光砖、平板门和细石台面，保持清洁使用逻辑，不用绒面或深孔粗糙材质铺满工作区。 |
| 邻近风格与误读 | 区别北欧的外露轻木框，本路线以软包连续曲面为主；区别法式不靠古典框线。禁充气泡泡、米色橡皮泥、满屋拱洞、家具融化、金色包边和全局暖黄。 |

### B 风格模块

```text
在原家具类别、数量、位置、朝向、座位关系和占位内作奶油风选型，保留原沙发组合及餐桌圆/方形态。通过真实软包构造、连续柔和曲线与浅色多材质表现温软。沙发用低连续弧背、大圆角扶手、少量宽坐垫分缝与内藏短脚；软垫有承重凹陷、布料拉力、接缝和边缘翻折，不像充气玩具。单椅采用紧凑马蹄或椭圆包裹靠背，独立下沉座面与短浅木脚。餐桌与茶几沿既定圆或方轮廓采用圆钝边浅石台面和内退稳定支撑，件数保持；餐椅为弧背软包、圆角座面和细短腿，厚度不吞掉实际坐面。床为圆角软头和清楚薄厚的软包床框，床头不越出床位，棉麻床品有自然褶皱；柜门暖白平板与浅木细节，保持封闭收纳，不改拱洞，彩平衣柜仍用统一抽象剖切。客餐用象牙色细砂石感哑光地面，卧室浅橡木有真实板缝与轻微色差，厨卫浅灰米砖石。室内立面为微暖白细灰泥、天花简洁暖白，墙体切面遵循母版。奶油白、燕麦米、浅杏软包和自然灰阴影分开，绒圈颗粒细小、棉麻织理密实、石面微孔克制、木纹自然。日光从原窗进入，在曲面形成连续明暗和落地接触阴影，不能全局黄染或平均打亮。已有台面少量浅陶和透明玻璃，留出使用面积。俯视清楚呈现弧背、圆角扶手、下沉坐面及软床头，避免塑料高光、巨大泡泡、轮廓糊化、满屋拱门、法式雕线和新增主要家具。
```

## 04 · 中古风

选择 20 世纪中期现代主义中轻盈木框与有机曲面的连贯方向；不把所有旧物、深木色或人工做旧都称中古。这个操作方向与北欧历史有交集，不作排他定义。

### 离线设计卡

| 维度 | 可执行设定 |
|---|---|
| 家具构造 | 沙发薄木框、窄木扶手、独立软坐背、可见修长脚；单椅有机木扶手与分离坐背。桌薄木面与内收刀口边，餐椅成型曲木靠背与独立坐面。床薄木框、微后倾木床头、独立床垫；柜为平板、抽屉及小木拉手，不为露腿把固定柜架空。 |
