# 03 · 固定彩平母版与执行

进入03前，确认用户已接受当前整理平面，或已明确委托代检。墙体、材质、采光和留白按下方母版执行；家具、材料和配色按所选风格模块执行。

## 三层提示词

1. **整体任务。** 写本次目标与每张实际附件的角色，调用下方固定母版。
2. **各房间的物品与布置。** 按整理图中的房间编号写物品用途、必要关系与已确认选择。不要写“右上卧室”或用全户型物品总数代替房间清单。
3. **风格要求。** 调用 [风格库](style-modules.md) 中所选的完整模块。

执行前展开母版与风格模块，展示完整文本及实际输入图。用户看到的文本与实际发送文本一致。不能只显示模块名，不临时缩写风格正文；验收标准和历史问题记录不发给生图模型。

随包彩平仅作材质表现、光影、留白与画幅参考。调用固定母版和完整风格模块，不从参考图抽取家具款式、颜色或布局来改写它们。附件职责采用 [选图说明](image-references.md) 中的固定角色文字；换样张只换图片，不重写这些要求。

母版中的〔〕是待填写项。执行前替换为本次实际内容，不把占位符发给生图工具。

## 固定母版

```text
【固定彩平通用母版】
依据上传的已核实整理平面，生成具有真实室内摄影质感的完整住宅彩平图。保持已有空间布局，在原家具占位内按风格完成成品选型。结合轮廓、文字和符号读图；附带确认信息用于澄清对象。确认信息与图纸实质冲突时先指出，不自行选择。
【输入图职责】
〔按实际附件顺序填写各图职责，使用参考说明中的固定角色文字；没有传入的参考图不写入请求。〕

保留户型外轮廓、朝向、比例、墙体与门窗开口、房间功能和通行关系；保留家具、柜体和设备的类别、使用能力及已确认占位与必要关系。数量、固定形状和方向按各房间清单。输入平面和基础模型是类别与占位依据，不是成品款式：沙发扶手与靠背、椅壳与木架、桌缘与支撑、床头与床架均按所选风格重新选型，允许曲线、角部内收、纤细构造与外露木架，不把输入矩形换颜色当作成品。不得外扩侵占通道或改变固定设备安装关系。活动家具的款式、构造、尺寸与摆放可在本案授权范围内按风格调整；未获授权时不改变组合、席位或功能。用户已指定型号或确认的具体设计继续保留。

严格垂直正交俯视。所有墙体采用连续、统一、低对比的浅灰细颗粒水泥剖面，保持原有厚度，不按 CAD 黑白填充分成不同材质；不出现厚重边框、夸张墙高、模型底座或户型外围悬浮阴影。低对比只约束墙体剖面，不把室内材质与光影一并淡化。

【剖切面与柜体】
这是屋顶隐藏、墙体剖切的正交俯视表现，剖切高度按本图资料确定，不编造尺寸。根据类别与高度判断可见面：低于剖切面的台面、矮柜和工作面显示水平顶面。已确认的挂衣柜保留连续柜腔、外框和原有分区，以一条细挂杆和垂直于它的一组成排短线，统一抽象表示挂衣；横竖柜只旋转同一图示并按长度调整短线数量。短线不变成闭合衣架、百叶、栏杆或暖气片，不画单件逼真衣物、布料色块、叠衣格或新增层板。只在已确认挂衣位置作这种表达；酒柜、鞋柜、橱柜及功能未确认的矩形不改作衣柜。其他封闭柜的水平顶面如确实可见，应为连续、薄边、浅接缝的完整材质面，不把CAD内框翻成凸起围边、敞口分格或柜门装饰。

【设备可见面】
洗衣机保持原图位置和占地。正上方只表现水平机顶；前开门洗衣机的圆形滚筒门属于竖直正面，不得转绘在顶面。机型未确认时用中性平顶，不臆造上开盖；只有确认是上开门，才在顶面表现盖板。其他设备也按真实朝向区分顶面和立面。

按真实有屋顶住宅计算光照：屋顶只对相机不可见，仍遮挡室外顶光。默认此彩平采用白天自然采光，室内灯关闭；用户另有时段与灯光要求时遵从并保持真实光源。默认场景中，日光仅由实际窗洞进入；窗边有方向清楚的日照与窗框投影，离窗较远处和背光处自然变暗，以窗边不过曝控制曝光，不把阴影整体提亮成灰白。反射光保留暗部物件，木、石、织物和墙面产生不同亮度与反射；不使用整屋均匀顶光，不仅给轮廓描一圈阴影。白平衡自然，不套统一黄滤镜。

家具要像真实生活尺寸的成品，被镜头从屋顶上方看见，不能像微缩模型或给平面轮廓统一填色。材质细节随物件尺寸变化，不用同一层噪点或锐化颗粒覆盖整屋。软包的软硬、厚薄、织物与承托骨架通过边缘、遮挡和接触阴影读得出来。
被面由宽缓的布料体积、受拉处的褶线、堆积处的松垂共同构成；床沿有受重力垂落的厚度和投影，枕头有鼓起中心、内凹接缝和受压边缘。床单与被子分层，不能把重复皱纹画在一块平板上。沙发靠背、扶手和独立坐垫各有正常厚度与缝隙，不形成一体塑料壳；微小褶皱服从织物受力，不作随机手绘线。
木板保持真实板宽、长短错缝、板间纹理与微光差异；织物细密吸光，地毯有纤维深浅，石材有细纹与宽柔微反射，金属玻璃仅在合适角度出现局部高光。被褥是厚软且受重力的织物，有宽而连续的起伏、较深谷部、细小交错褶皱与松弛边缘，不能在平板上印皱纹。沙发坐垫因填充与缝线形成柔软受压体积，软包与支架分明。避免纸折床品、塑料、绘画描边、动漫、等距重复贴图和统一噪点。材质颜色由风格模块决定；未指定时采用简洁中性表达，不当作已确认设计。餐桌、茶几与厨房台面的可移动小物按风格、用途与可用面积安排，不设统一件数。植物、花器和器物分别选型，不机械重复。柜体在已确认功能与范围内，按风格组合封闭、玻璃和开放展示，并安排有用途的陈设；未确定用途的柜体不随意开格或补不明形状。陈设不代替设备，不遮挡电视、水槽、炉灶、轨道、柜门及操作与通行空间。

【画布与轮廓边界】
默认16:9纯白画布，完整户型连同阳台、外凸设备位及门扇等比居中，四周保留至少约10%的宽裕留白；按可用宽高两者中更紧的边界适配，不拉伸、不裁切。用户指定画幅时采用其画幅；极长窄户型可选更合适画幅，不能为填满画布改比例。保持这圈明显宽裕的留白，不为放大家具细节而放大户型。户型外是均匀纯白的图纸留白，不是放置模型的承托地面，不参与光照。所有日照、接触阴影与环境遮蔽仅发生在户型内部；以建筑与门扇的实际实体轮廓为干净截止边界，边界之外直到画框边缘全部均匀纯白；包括入户门下方、厨房底边和每处凹角，都不残留投射阴影、接地灰影、暗晕、背景渐变、平台、底板或可见外墙立面。室内继续保留真实日照明暗，不能为消除外部阴影而压平室内光影。

去除人物、尺寸、文字、箭头、门开启弧及柜体辅助 X 线，不破坏建筑轮廓、开口及物件的类别、数量与占位。最终仅输出无标注彩平图，无图例或 Logo，尽可能保留原生细节。
```

## 执行与检查

通常实际输入为“本案编号整理平面＋一张彩平表现参考”。图1提供物品、占位与空间；图2只参考纹理尺度、材质反射、软包体积、光影和画面组织。家具、材料类别、配色、植物与陈设按固定风格模块和本案信息选择，不复制图2的设计。必须实际传入图2，不能只在文字里提它。

按 [选图说明](image-references.md) 选择参考，优先采用容易隔离表现与设计的图；无需每次运行搜集新图。没有可用参考时说明改用完整文字，仍保留原母版和风格模块。尽量使用平台原生高质量输出，放大和锐化不等于恢复细节。

按房间回查原资料与用户确认，再检查成图：

- 空间与物品：墙门窗、连通、固定设备、物品是否存在及使用关系。
- 使用：可开门、可操作、可通行；设备可见面与柜体图示是否合理。
- 风格与质感：家具构造、材料、配色、植物与陈设是否符合本套风格；软包和床品是否有厚度与自然褶皱；木石纹理尺度、材质反射和窗光是否符合上方母版要求。
- 画面：编号、文字、分类色、辅助线、外投影与裁切是否残留。

通用彩平不把蹲便器精确外形与排水方向作为通过条件，也不为它追加替代表达指令。用户明确要求此项时另行确认验证范围。

明确漏画或错画按已确认方案自行处理。留存每次实际输入、完整文本与输出，说明改了什么。关键空间错误回查最早依据，不把长串否定句当作纠错方法；局部编辑不再附整屋重新选型任务。更换主要设计或风格先确认。

按相近显示尺度查看材质、光影、留白与画幅，对照 [彩平表现参考](image-references.md)。自检与用户接受分开记录。彩平确认后保存本套已选家具与材料，后续效果图继承；生成模型仍可能重绘错，检查不能变成准确度保证。
