# 跨平台使用：由宿主 Agent 完成适配

本 Skill 提供四阶段方法、离线 Prompt、参考样张和验收规则。豆包、Kimi、Work Buddy 或其他宿主负责把这些逻辑步骤映射到**当前可用的模型、工具、文件和交互界面**。品牌名称不能证明能力；本包没有为它们虚构同名 API，也不要求特定生图服务。

## 给目标平台 Agent 的入口

把完整 Skill 包交给能读文件的 Agent；只支持聊天附件时，交付本页、当前阶段文档及真实图片。可复制：

```text
请先适配并执行 cad-plan-to-room-render，不要重写它的设计规则。
1. 读取 SKILL.md 和 references/adapter-contract.md，只探测本次任务需要的真实能力。把文件读取、图片理解、图片生成/编辑、输出看图、保存及用户确认分别标为可用、不可用或未验证。
2. 将逻辑步骤绑定到你当前真正拥有的工具。无法执行的动作给出可行替代，不能把工具名称猜出来，不能把路径字符串当成已上传图片。首次调用前检查当前阶段文档和附件是否实际可读。
3. 用本地适配说明记录宿主工具、输入限制和保存方式；上游的空间约束、参考角色、质量检查和逐步确认规则保持不变。适配说明属于本平台，不覆盖原 Skill。
4. 依次执行：01识别原始资料→确认目标方案和关键疑点；02整理平面→确认整理结果；03生成彩平→确认本套设计；04先确认广角/近景或组合，制作并核对每个机位的空间约束图，实际传图后生成房间效果图→确认结果。所有成果、完整提示词和确认问题在当前对话展示，以用户回复为依据；不另建审阅页、确认单或确认记录文件。仅说“做全流程”不等于放弃节点确认；用户明确授权自主推进时，记录适用阶段并继续自检。
5. 记录真实 Prompt、按顺序传入的图片及角色、当前成果版本、自检和用户确认。缺少持久化工具就以一条可复制的运行记录交付。迁移或恢复时先核对当前版本，不靠上个会话的隐含记忆。
本次任务：〔资料、目标阶段、风格、房间〕。
```

首次只需向用户说明已经能读取什么、当前阶段和下一步需要什么。能力清单是 Agent 的执行依据，不要求客户配置接口或阅读技术表格。没有资料且只是询问功能时，先介绍四步产物，引导上传 CAD/PDF/平面图片，不启动生成。

## 适配边界

[适配契约](adapter-contract.md) 和 [JSON 示例](../examples/platform-adapter.example.json) 规定最小输入、状态与交接字段，**不是 SDK，也不是已经连通的服务**。宿主可通过工具、原生工作流或人工上传实现它；不能仅生成一份 JSON 就声称适配完成。

| 本次真实能力 | 采用的路径 |
|---|---|
| 读完整包、看图、携图生成、查看输出 | 按四阶段运行，选择当前阶段文档和参考；有代码工具才启用可选结构化处理。 |
| 可看图和携图生成，不能读 Skill 文件夹 | 提供当前阶段文字和逐张图片；由宿主保存或在消息中返回简短状态。不要假定 ZIP 已解包。 |
| 不能读取 DWG | 若能可靠转换则先转换并检查；否则引导提供 CAD 导出的 PNG/PDF/DXF。收到图片即可走图片路径，不能宣称已读取原生 CAD 几何。 |
| 可看图，不能生成 | 可以识别、核对、组装完整 Prompt 和附件清单；停在“待外部执行”，让用户选择已授权的生图入口。 |
| 可生成，不能编辑 | 错误可通过重新生成处理；不能承诺局部修改会保持其他区域。 |
| 可生成，不能看生成图 | 记录生成完成，视觉自检为未完成；交有看图能力的一方核验，不宣称通过。 |
| 用户确认 | 仅在当前对话接收回复，指向本轮展示的成果版本；不需要专用界面或确认文件。没有回复、超时或仅收到下一条无关消息都不是同意。 |
| 无持久化或无法查询异步任务 | 返回可复制的运行摘要/任务标识；说明恢复边界，不伪造已保存、后台持续运行或已取消。 |

联网不是风格执行的前置条件：直接加载包内 [风格模块](style-modules.md)。研究来源另存于维护附录，普通生成不加载；链接不可达不阻断已有模块。所需图片缺失或平台图片数量有限时，先保留结构依据，明确减少了哪些质量参考，不能暗中切换方法后继续声称质量等价。

## 每个阶段传什么

| 阶段 | 必要内容与确认点 |
|---|---|
| 01 原始资料识别 | 原文件/可读导出图、用户已知信息；确认目标方案、方向/尺度已知程度和影响后续的疑点。 |
| 02 整理平面 | 已确认原图和事实、[平面整理规则](prepare-plan.md)；输出整理图与变化摘要，确认无误再用作后续依据。 |
| 03 彩平 | 当前确认的整理图、个案事实、[彩平母版](color-plan.md)、一个本地风格模块；按[选图清单](image-references.md)只传当前风格的一张适用辅助图和对应借鉴/排除说明，不传整个参考库；缺图显式校准，不自动换成其他风格。用户确认选定版本后固定本套选型。 |
| 04 房间摄影 | 当前确认的整理图及本套彩平、选型记录、[房间方法](room-render.md)与镜头说明；对应机位的空间约束图必须先制作、核对并实际传入；景别未明确时先问用户，摄影参考按需附。每个房间结果接受后才能记为完成。 |

仅做中间阶段时可承接用户提供的已确认成果；先核对它可读、对应当前方案且覆盖本阶段所需信息，不强迫重做已有阶段。已有确认不能从文件名“最终版”猜测。

## 迁移与恢复

带走一份案例目录或同等附件包：当前原件/整理图、选定彩平和房间图、个案事实及选型、实际 Prompt/图片角色、版本和确认记录。接手方核实文件实际可读后恢复到最后一个有效节点。结构依据被替换时，下游生成图和确认标为过期；只替换某风格彩平时，该风格房间图过期，其他未受影响的风格不重置。

先在目标平台检验一个彩平和一个房间，再扩大数量。适配通过仅表示资料、工具和交互能接通；不同模型的视觉质量仍要实际出图核验。本包不宣称豆包、Kimi、Work Buddy 已完成同等整链验收。
