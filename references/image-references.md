# 参考图选择与用途

本包保留 V1.2 的两张彩平质感下限和一张摄影示例；新增十张 r4 风格示例。r4 获认可的是风格表达，不是空间准确度。它们是效果图，不能当作当前户型或彩平布局模板。

## 本次怎样选图

- 通常只传“本案整理平面＋当前风格的一张适用参考”。不上传十张，不自动额外传两张质量图。
- 用户已有适合本次方向的图，先看图并说明角色。否则选择下面当前风格的 r4 示例。
- 风格图提供家具构造、材料、配色、植物、花器、陈设与写实质感。完整文字仍须展开；图里没画出的要求由文字说明。
- 图1提供房间、物品、占位与空间关系。图2不提供本案墙门窗、家具数量、机位和门开闭状态。
- 彩平的正交俯视、剖面、自然光、编号移除及留白服从母版。不能把效果图的天花、亮灯或摄影透视搬入彩平。
- 效果图继承已确认的本套彩平与设计记录。另一案例的 r4 图只延续风格，不重新替换整套家具。
- 平台不能实际传参考图时，说明降级为完整文字，质量待校准。不要假报传图或承诺等价质量。

## 实际角色文字

仅在确实传入这两张图时，填写下方内容。生成前展示完整请求及真实图片。

```text
图1是本案已确认的编号整理平面，提供房间、物品类别、占位和空间关系。家具块不指定成品款式。
图2是本次〔风格〕参考。借鉴〔本图具体家具构造、材料、配色、植物、陈设与质感〕，将这些特点转译到图1的正交俯视彩平。完整风格文字补足未显露的要求。
本案布局、墙门窗、物品数量与必要位置关系由图1及各房间清单决定。不要复制图2的建筑、家具布局、透视、机位、门状态和已知空间错误。
```
