# 造型参考 → 本房设计要求

风格确定后，在03补全未定柜体、墙板和岛台；在04的空间约束图核对后，补全未定吊顶、照明及门柜连接。已有选型直接承接。完整包带有[造型库浏览入口](form-library/index.html)、结构化数据及检索工具，复用现有接口。

下载完整ZIP后无需另装造型库或配置路径。接口优先采用显式 `INTERIOR_FORM_LIBRARY_ROOT`；未配置时保留原项目同级独立库接入，否则使用包内快照。显式路径错误须报错，不静默换库。本机独立库是维护主版本，包内库是发布快照，不双向自动同步。见[随包使用说明](form-library/使用说明.md)。

## 检索与选择

```sh
python3 scripts/form_library.py search --category 吊顶 --room 客厅 --limit 5
python3 scripts/form_library.py search "悬浮" --category ceiling
python3 scripts/form_library.py show FORM_ID
python3 scripts/form_library.py select FORM_ID_1 FORM_ID_2 --room 客厅 --style 中古风
```

类别支持 ceiling/wall/island/cabinet/door 或中文。先按应用部位、房间尺度、已有梁柱/门头、通道和净高条件筛选，再看风格。风格标签是编辑建议，不是唯一归属。先读已有视觉观察和出处；形态有重要疑问且可联网时再看对应照片，不凭标题或缩略图推导未知部分。

文字特征、相似形式区别、组合建议和来源记录可离线检索。照片与出处网页仍是在线资源；大陆访问状态不能用本机可达、海外测试、DNS或一次超时推定。照片打不开时按已有观察文字选型，记录“本轮未打开原图”，不阻断已清楚的形式选择；重要形态仍不清楚就换条目。同样适用时优先实际可访问的来源，不改成未经核验的镜像地址。

本流程的未定吊顶默认范围：

- 客厅：边吊或整面退让悬浮平顶。
- 卧室：平顶或局部边吊。
- 用户已有确认方案优先；其他房间按用途补全，不能把客卧选项套给全屋。

整面悬浮平顶是一块连续主体平面，边缘与墙面退让；多块悬浮岛板是分离的多个板块，不可混用。周边低带与中央高平顶也不能误写成中央低板。照片中的坡顶、商用格栅和高窗不能带入本案。

同风格无匹配时，去掉风格筛选，选择与空间相容的通用形式，并说明材料/颜色是本案适配。仍无合适条目就记录缺项，不编造案例、ID或图片地址。缺少净高或设备条件时把尺寸标为设计补全，不声称已经验证施工。

## 从参考形式转成可执行要求

不把整段检索结果塞进提示词，也不只写“参考某案例”“高级、合理、美观”。为本房选一套相容形式；只深化当前未定且相关的构件。每项写清：

| 要素 | 写什么 |
| --- | --- |
| 来源与取舍 | 造型ID、观察的照片/出处；借用哪些特征，排除哪些特征 |
| 应用对象 | 本案哪个柜体、哪段墙、哪个门上方或哪片天花 |
| 形式与范围 | 轮廓、分区、覆盖边界、端部及转角；尺寸有依据才写为已知 |
| 连接 | 与墙、柜顶、门上饰面、隔断门头的连续或分离关系 |
| 材料适配 | 沿用已定材料；未定材料按本案风格选择并注明是设计补全 |

例如：

```text
吊顶借用周边降板顶的“低边带框住中央高平顶”。本案只在客厅设置单层连续边带，中央为水平平顶，转角连续；柜顶以同色封板收口。排除来源照片的坡顶与三角窗。
左侧高柜借用开放封闭组合：指定正面上部为展示格，下部为封闭收纳；保持原柜体范围，不把展示架移到电视上方。木色及柜门材料按本案选型。
```

灯光另写照明对象、灯具类型、总数量、相对位置及安装方式。按本房功能与选定吊顶安排，不给所有房间统一灯数，也不把灯带当作全部照明。可按电视墙、沙发、茶几、餐桌和工作面说明灯位；具备原平面坐标时再用坐标。不可见或无法确定的灯位标为未核验。

这些具体要求用于设计引导。用户明确指定的条件继续遵守；Agent选出的灯数、分格、纹理和小物允许合理变化，最终按[方案表达标准](room-render.md#自检修正与停止)决定是否修正，不逐项复刻参考照片。

## 实际输入与沿用

默认读库内观察特征，必要时看参考照片，再转成本房设计要求。记录实际采用的方式：“本轮在线看图，未作为附件”“仅用库内既有观察文字”或真实附件顺序与用途。库中的URL不是上传凭证。第三方原图的下载/上传许可和平台能力须核实；不能把在线看图记成携图生成。

原平面、空间约束图决定空间；已确认选型决定本案设计；外部案例只提供已注明的构件特征。完整风格模块只作用于本房实际已有物件，不能带入案例布局或新增家具。

把来源ID、应用部位、借用/排除特征、材料适配、灯光安排和确认/代检状态并入已有案例记录，不另建确认单或第二套状态。主视角经确认或明确委托代检后，各机位沿用同套设计，执行见[空间与摄影方法](room-render.md)。

本模块不要求精细3D建模。包内工具使用Python标准库；没有代码工具时可读JSON或浏览页选型。外部照片未包含在ZIP，来源、署名与原图权利记录保留，见[来源说明](../NOTICE.md)。
