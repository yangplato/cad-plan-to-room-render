# 04 · 空间约束、参考选型与摄影

默认流程：**空间约束图 → 参考库选型 → 本房设计要求 → 主视角效果图 → 同空间其他视角**。

进入04前承接已确认的整理平面、本风格彩平及选型，或明确委托代检的阶段成果。已确认外部成果不重做，但核对空间来源与版本。用户明确授权只测试“约束图→效果图”节点时，记录空间来源和本轮设计范围；不补做未要求的彩平，也不把试验设计写成已确认03选型。交互规则见[用户引导](user-journey.md)。

## 制作与检查空间约束图

先按用户已定的广角/近景、房间和批次执行。未定景别时给建议并确认；已有确认不重问。

从已确认平面读取墙门窗、柱梁、固定设备、柜体范围、隔断门头位置、通道、家具类别/占位/朝向和可见邻室。在可站立区域选机位，回标相机、视线和视野，再从同一空间依据输出各机位图。优先沿用已核实的简模或体块投影，无需精细家具模型。

- 墙体通高；不为取景删墙、移门或改变连通。检查墙端、进退、柱、设备方向及遮挡。
- 家具只表示类别和占地，不规定成品扶手、桌腿、曲面、颜色或材质。保持必要空隙，不以落地实心盒子误判桌椅遮挡。
- 未确定吊顶用平顶占位，不提前建灯具；提示词明确这是未完成设计。已有确认的吊顶和灯具继续沿用，不抹去已定设计。
- 保留已确定的墙板/柜面覆盖区域、门上同柜饰面区域及隔断门头外轮廓。未定部分明确由本房设计要求补全，不从体块颜色推断成品颜色。
- 没有三维工具时，给出相机、视线、视野及可见/遮挡关系的平面视线图，说明未做三维投影验证。文字清单不能代替实际图。
- 换机位或结构版本，更新约束图。仅同机位材质、小物纠错可以沿用有效图。

空间约束图为必要图像输入，但不是图像模型的硬约束或准确度保证。它保留真实空间关系，不要求逐像素复制粗模家具。

## 参考选型与本房设计要求

按[造型库方法](form-library.md)深化当前未定构件。先检验房间尺度、功能和既有结构是否相容，再看风格。已有彩平的家具构造与材料继续沿用；体块占位不能另行定款。彩平剖切或柜体俯视揭开，也不代表立面全部开放。

生成主视角前，在现有案例记录中形成一段本房设计要求：

- 吊顶：选定边吊/整面悬浮平顶或卧室平顶/局部边吊，写清主平面与边带高低关系、覆盖范围、转角、与柜顶及门头的收口。尺寸缺依据时注明为设计补全。
- 照明：按会客、餐桌、墙面和工作面确定所需照明，不强制每类加满。写清灯具类型、数量、相对位置、嵌入/明装方式与照明对象，避免直射屏幕；灯带只承担约定的间接光。
- 饰面与柜体：写清开放/封闭分区、端部形式、墙板覆盖边界及门上同柜饰面的连续关系。展示格必须指向具体柜体，不能移到其他墙面。
- 门与隔断：保留门洞、开启关系和门头位置；顶部门头与吊顶、柜体的外观连接要清楚。照片看不见的轨道或三联动运动不算已验证。
- 家具：按本房实际类别与数量在占位内选款。风格模块中提到单椅或吧凳，不代表当前机位必须新增或强行凑齐。

主视角可以在已定边界内补齐未表达细部；不能把所有吊顶与灯光都交给“合理、美观”一句话。参考来源、借用/排除特征、设计补全与实际图像附件分别记录。

## 实际提示词与输入

在当前对话展示真实输入图和完整展开提示词。原平面/彩平承接已确认版本；本机位约束图必须实际传入。只为真实附件写编号与职责，不把空白占位符、假路径或“若有”选项发给工具。明确委托自主推进时省略授权范围内的人工等待，仍完成约束图及展示。

提示词保留三层：整体任务与输入职责；本房实际物件、空间关系及设计要求；所选完整风格模块。具体本案选型优先，风格段只能延续本房已有物件及补全未定部分。

```text
生成本方案〔房间、机位〕的单张写实室内效果图，〔实际画幅〕。
实际附件职责：〔按实际顺序列出原平面/彩平、当前机位空间约束图及本方案主图〕。当前约束图提供空间、机位与遮挡；家具体块只表示占位。未设计的平顶允许按下述要求补全。外部构件照片〔写真实使用方式，未传则不列为附件〕。
空间与物件：〔本房及可见邻室的墙门窗、柱梁、门头、固定物件、家具类别/数量/占位及关键连接〕。保留取景中的可见关系；未入镜物件不搬进画面。
本房设计要求：〔选定吊顶形式和范围、照明对象/灯具数量/灯位/安装、柜体分区与端部、饰面范围与门柜连接；参考形式的借用和排除〕。
摄影：〔真实机位、视线、主体、前中后景和取景边界〕。自然竖线与透视，不用超广角拉大空间。自然光有方向，暗部有细节，材料有真实厚度、接缝和纹理尺度，无统一黄滤镜或强HDR。
风格要求：〔完整展开本风格模块〕。只落实本房实际物件，不因风格段新增家具；已选款式和材料优先。
只补全明确未定的细部。输出单张摄影图，无文字、Logo、水印或拼图。
```

## 主视角与其他视角

先生成代表性主视角，检查设计和空间。通过用户确认或当前明确委托代检后，把选定版本、吊顶形式、可见灯位、柜体分区、材料与家具款式并入现有案例记录。代检不等于用户接受。

后续机位实际传入“自己的空间约束图＋本风格选定主图”。主图只延续设计、材料和款式，不提供新机位的墙门窗、家具数量或相机。提示词写明继承哪些内容；新机位不能重新随机设计天花、灯具或家具。

首图未入镜/遮挡处不算已经确认。按同一设计要求补全，在首个可见机位检查；无法确定的关系标为未核验，不从首图反推原方案。平台不能携主图时说明连续性能力缺项，可用已记录设计文字继续，但不得声称完成了双图连续性验证。

## 自检、修正与交付

每张图分别检查，画面氛围不能抵消空间或构件错误：

- 设计形式：吊顶高低与比例、转角收口、灯具搭配、柜体分区及材料范围是否符合本房要求。
- 空间与使用：墙/洞口/柱/门头/设备/家具位置、数量、通道、机位与遮挡；门柜、工作面及照明对象是否合理；是否出现额外家具、重复把手或错机顶。
- 多视角连续性：同一吊顶类型、可见灯位关系、柜门分区、材料和家具款式是否延续。看不见的部位不记为通过。
- 摄影与质感：构图、透视、曝光、纹理与真实光源；明显画质退步另记。

对可见问题写清是设计未确定、约束图表达错误，还是生图未遵守输入。明确空间错误回查识别、机位和图像输入，不只反复写“移门、缩墙”。同方案漏画错画自行修正，默认至多两轮；保留首图及全部修正。达到上限仍有关键错误，展示残留问题，不标通过。主要设计或风格改变按当前授权确认。

在当前对话按风格分组展示真实图片、实际输入、完整提示词与简短核验说明，不另建审阅页或确认单。状态并入已有案例记录；自检、代检和用户接受分别写。上游空间或选型换版时标记相关机位待复核，已确认旧图留存，不扩大历史接受范围。
