# 参考图选择、用途与来源

此页是选图入口。十种风格都有完整离线文字；包内目前有 **9张同风格试用彩平＋1张摄影示例**。意式轻奢暂缺适合默认传图的样张。试用资格只表示有可借鉴属性，不是全图无误、适配新户型成功或十风格稳定性认证。

## 当前任务怎样选图

1. **先固定本案依据。** 03必须保留已确认的整理平面与本图事实；04使用本案平面、已确认彩平和设计记录。任何参考都不能代替它们。
2. **03通常只选一张辅助图。** 用户提供适合当前方向的参考时，先看图明确可借鉴内容；否则从下表选择当前风格的试用图。同一张图可同时承担款式和质感，不再自动叠加意式/法式质量图。不要上传整个参考库或混入其余九种风格。
3. **完整文字继续生效。** 实际请求包含母版＋本案事实＋单一风格块＋图片职责及排除项。参考只提供表中已核验属性，未显示的家具构造由设计卡补足；与当前文字要求冲突的属性不采用。用户明确指定的本案设计优先，但不把旧参考的尺寸与布局当本案事实。
4. **缺少适用图时显式降级。** 例如意式轻奢：有适用的用户参考就核对使用；否则以整理平面＋完整文字先做一张待校准小样，并告知没有适用参考，不能承诺同等质感。用户明确要求先保证参考条件时，先取得适用图。不得偷偷拿意式极简、法式或未入库图兜底，也不为凑齐十种而自动制作新图。
5. **附件限制优先保护结构。** 平台只容一张图时保留整理平面，说明参考未传；文字不裁掉关键空间与风格要求。若必须增加局部清晰结构图，可按实际能力追加；“一张辅助图”是防混用原则，不是阻止提供必要结构依据的硬上限。
6. **04承接当前方案。** 已确认本套彩平与设计记录负责家具和材料，不重新加载风格库样张选款。只有确有构图需要才加摄影示例，并限于景别、材质与光；不照搬旧户型机位、门墙或遮挡。

所有选中图片都要实际查看并通过宿主支持的方式传入。文件路径、Markdown链接和“参考图已加载”的口头陈述不能代替像素输入。记录选择原因、借鉴/排除项、实际顺序与角色；若无法传递职责说明或看图核验，库图只作人工对照，不能自动附图后宣称受控。

## 质量比较与摄影示例

- **质量下限对照：**意式极简与法式复古两图用于把输出放到同显示尺度，比较软包体积、床品、木石纹理与光照。比较时不要求新图复制它们的材料颜色或家具。此项主要是Agent/用户看图核验；只有当前风格匹配上表时，才同时作为默认生成辅助图，不自动多上传两张。
- **摄影示例：**[客餐厅摄影](photography-living.png)示范中轴、近中远景与自然光。当前空间允许才采用相应构图；不为模仿它挪墙、改门或复制家具。
- “接近九成”是用户审美目标，不是已计算的百分比。图片只能证明实际可见的尺度和细节；不把不足像素中的微纤维、构造节点称为已核验。

## 实际附件角色段示例

仅在确实传入这两张图片时使用；填入所选行的具体借鉴项和排除项，删除空占位。

```text
图1是本案已确认整理平面，决定墙门窗、房间连通和所有主要物件的类别、数量、位置、朝向及占位。
图2是〔当前风格〕参考，只借鉴〔该行款式/材料/质感〕；其余选型按本次风格文字补足。不要继承图2的户型、柜内线条、洁具、家具数量、陈设位置、白边，也不要复制〔本图专属排除项〕。
图1与本图确认信息决定本案事实；图2不提供尺寸或布局。小物只在母版已允许的台面范围内按新方案安排。
```

“纯文字”在本工作流指**不附质量/风格参考**，仍需本案整理平面。参考选择规则适用于各宿主，实际传图、限额和生成模型由[平台适配](adapter-contract.md)处理。

## 后续只补必要样张

意式轻奢先补一张合格候选；其他风格在真实新案出图或用户提供更好参考时择优替换。每个风格默认保留一个清楚的选择，记录来源、版本、哈希、借鉴项与排除项；不按成功一次推断稳定。引入陌生户型先试一套，核验结构污染、风格与质感后再扩大。受限整图仍反复污染时才考虑适用局部参考或取消附图，不预先扩建家具资产库。

研究依据位于[维护附录](../docs/style-research.md)，用于修订与查证，普通生成不读取；品牌名、网页和研究原文不拼进实际生图Prompt。
