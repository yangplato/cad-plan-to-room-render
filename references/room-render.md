# 04 · 空间约束、参考选型与摄影

默认流程：**空间约束图 → 参考库选型 → 本房设计要求 → 主视角效果图 → 同空间其他视角**。

默认成果用于风格评判、方案调整和直观看懂平面。主要空间关系可信、布局逻辑成立、硬装衔接顺畅、软装摆放合理、装饰协调、有氛围且整体完成，就达到本阶段目的。用户明确要求准确度实测或构造复现时，才按其指定对象提高检查精度。

进入04前承接已确认的整理平面、本风格彩平及选型，或明确委托代检的阶段成果。已确认外部成果不重做，但核对空间来源与版本。用户明确授权只测试“约束图→效果图”节点时，记录空间来源和本轮设计范围；不补做未要求的彩平，也不把试验设计写成已确认03选型。交互规则见[用户引导](user-journey.md)。

## 制作与检查空间约束图

先按用户已定的广角/近景、房间和批次执行。未定景别时给建议并确认；已有确认不重问。

从已确认平面读取墙门窗、柱梁、固定设备、柜体范围、隔断门头位置、通道、家具类别/占位/朝向和可见邻室。在可站立区域选机位，回标相机、视线和视野，再从同一空间依据输出各机位图。优先沿用已核实的简模或体块投影，无需精细家具模型。

- 墙体通高；不为取景删墙、移门或改变连通。检查墙端、进退、柱、设备方向及遮挡。
- 家具表示功能类别、主要使用区域和体量，不规定成品扶手、桌腿、曲面、颜色或材质。可在区域内合理完善款式与摆放，保留通行和操作空隙。粗模的可见椅数不自动成为席位要求；原方案的使用需求和用户明确指定的数量继续保留。
- 未确定吊顶用平顶占位，不提前建灯具；提示词明确这是未完成设计。已有确认的吊顶和灯具继续沿用，不抹去已定设计。
- 保留已确定的墙板/柜面覆盖区域、门上同柜饰面区域及隔断门头外轮廓。未定部分明确由本房设计要求补全，不从体块颜色推断成品颜色。
- 没有三维工具时，给出相机、视线、视野及可见/遮挡关系的平面视线图，说明未做三维投影验证。文字清单不能代替实际图。
- 显著更换机位、改变可见关系或结构版本时更新约束图；小幅取景优化及同机位纠错可沿用有效图。

空间约束图是实现效果图的必要输入。它保留主要空间关系、布局逻辑、视线和遮挡；模型形状、色块、灯孔和占位细节不是默认验收基准。取景可在真实空间内优化，显著换机位或改变可见关系时才更新对应图。

## 设计要求的效力

在现有案例记录中区分三类内容，不新增评分表或精度配置：

- 必须保留：原资料的主要墙门窗、连通、固定设备和使用关系，以及用户明确指定的产品、形式、席位或尺寸。
- 本案设计引导：Agent按参考选定的吊顶、照明、柜体和材料。提示词可写具体数量与分区，成图的合理变化可保留；这些文字不自动变成逐项复现指标。
- 可自由完善：家具细部、局部装饰、摆件、纹理及光影表现。在主要占位和功能边界内完善即可。

用户接受整张图，表示该图可用于当前方案评判，主要设计可供后续延续；仅明确指定或确认的细部才成为精确规格。Agent代检仍不等于用户接受。

## 参考选型与本房设计要求

按[造型库方法](form-library.md)深化当前未定构件。先检验房间尺度、功能和既有结构是否相容，再看风格。已有彩平的主要家具特征与材料继续沿用，细部可完善。体块占位不另行定款；彩平剖切或柜体俯视揭开，也不代表立面全部开放。

生成主视角前，在现有案例记录中形成一段本房设计要求：

- 吊顶：选定边吊/整面悬浮平顶或卧室平顶/局部边吊，写清主平面与边带高低关系、覆盖范围、转角、与柜顶及门头的收口。尺寸缺依据时注明为设计补全。
- 照明：按会客、餐桌、墙面和工作面确定所需照明，不强制每类加满。写清灯具类型、数量、相对位置、嵌入/明装方式与照明对象，避免直射屏幕；灯带只承担约定的间接光。
- 饰面与柜体：写清开放/封闭分区、端部形式、墙板覆盖边界及门上同柜饰面的连续关系。展示格必须指向具体柜体，不能移到其他墙面。
- 门与隔断：保留门洞、开启关系和门头位置；顶部门头与吊顶、柜体的外观连接要清楚。照片看不见的轨道或三联动运动不算已验证。
- 家具：按本房功能和主要使用区域选款，指定席位与数量继续遵守。风格模块提到单椅或吧凳，不代表必须新增；普通软装组合可合理完善，不按粗模边线逐件复刻。

主视角可以在已定边界内补齐未表达细部；不能把所有吊顶与灯光都交给“合理、美观”一句话。参考来源、借用/排除特征、设计补全与实际图像附件分别记录。

具体提示词帮助形成完整方案。最终检查按上述交付目的执行，不把Agent的所有设计引导逐条变成返工任务。

## 实际提示词与输入

在当前对话展示真实输入图和完整展开提示词。原平面/彩平承接已确认版本；本机位约束图必须实际传入。只为真实附件写编号与职责，不把空白占位符、假路径或“若有”选项发给工具。明确委托自主推进时省略授权范围内的人工等待，仍完成约束图及展示。

提示词保留三层：整体任务与输入职责；本房实际物件、空间关系及设计要求；所选完整风格模块。具体本案选型优先，风格段只能延续本房已有物件及补全未定部分。

```text
生成本方案〔房间、机位〕的单张写实室内效果图，〔实际画幅〕。
实际附件职责：〔按实际顺序列出原平面/彩平、当前机位空间约束图及本方案主图〕。当前约束图提供空间、机位与遮挡；家具体块只表示占位。未设计的平顶允许按下述要求补全。外部构件照片〔写真实使用方式，未传则不列为附件〕。
空间与必须保留的内容：〔本房及可见邻室的主要墙门窗、柱梁、门头、固定设备、家具功能/使用区域、指定数量与关键连接〕。未入镜物件不搬进画面。
本房设计引导：〔选定吊顶形式和范围、照明对象/灯具组合/灯位/安装、柜体分区与端部、饰面范围与门柜连接；参考形式的借用和排除〕。在必须保留的边界内合理完善细部，使整体协调完整。
摄影：〔真实机位、视线、主体、前中后景和取景边界〕。自然竖线与透视，不用超广角拉大空间。自然光有方向，暗部有细节，材料有真实厚度、接缝和纹理尺度，无统一黄滤镜或强HDR。
风格要求：〔完整展开本风格模块〕。按本房功能与主要占位落实，不因模板列举而强行凑齐；已选主要款式和材料优先。
目标是可供风格评判的完整方案，空间可信、硬装衔接顺畅、软装摆放合理、美观且有氛围。输出单张摄影图，无文字、Logo、水印或拼图。
```

## 主视角与其他视角

先生成代表性主视角，按方案表达标准检查。通过用户确认或当前明确委托代检后，把选定版本、主要吊顶形式与区域、照明思路、主要柜体外观、材料和主家具特征并入现有案例记录。

后续机位实际传入“自己的空间约束图＋本风格选定主图”。当前图决定空间，主图延续同一主要方案：吊顶形式、灯具组合、主要柜体与材料、主家具特征。不同角度不能变成明显不同的两套设计；灯孔、木纹、柜门小分格和摆件无需逐个复制。主图不提供新机位的墙门窗、数量或相机。

首图未入镜处按同一设计思路合理补全，不从首图反推原方案。只检查实际可见、且影响当前方案判断的关系；不用补镜头核验隐藏轨道或构造。平台不能携主图时说明能力缺项，可用已记录设计文字继续，但不得声称完成双图验证。

## 自检、修正与停止

每张图出图后做一次整体检查：空间与使用是否可信，硬装与软装是否协调完整，风格和氛围是否清楚，其他视角是否延续同一主要方案。修正按偏差的后果决定：

| 判断 | 处理 |
| --- | --- |
| 会误导平面理解、明显影响使用、违反用户明确要求、硬装穿插，或明显残缺/失真到无法判断方案 | 必须针对性修正，例如改变门墙关系、堵通道、柜顶穿入门洞、整体灯光缺乏设计、主要软装缺失。 |
| 与粗模、Agent引导或首图有小差别，但空间与使用成立、设计协调完整 | 可供评判，直接交付。例如未指定灯数的小变化、柜门小分格、木纹、摆件，或同区域内合理的沙发造型与软装组合。 |
| 存在多个合理方案，如配色偏好、沙发类型、装饰多少 | 展示当前完整方案供用户选择，不为Agent自己的偏好继续生图。 |
| 部位未入镜、被遮挡或无法判断 | 不记为精确通过；仅在影响当前判断时说明未知，不扩大核验范围。 |

可供风格和方案评判就停止修图，交用户审阅。普通灯数差异不会因写进提示词而自动成为错误；用户指定灯数时则按指定执行，遮挡灯具不强行搬入镜头。主材略有色差可接受，主要饰面范围变化到使方案明显不同则需要修正。

必要修正前用一句话说明它影响什么判断，以及只修什么。先修最影响方案理解的部位；回查错误最早出现在设计、约束图还是生成阶段，不为细节全面重建。每轮修后整体成立就停，较小偏差导致整体画质或设计退步时保留较完整版本。

同一方案、同一机位首图后的累计修正至多两轮。这是上限，不是默认次数，不能另起请求重置计数。达到上限仍影响判断时，展示较完整版本及残留问题；用户明确要求再深化才继续。用户说停止立即停止。主要风格或设计改变按当前授权确认。

在当前对话按风格分组展示真实图片、实际输入、完整提示词与简短核验说明，不另建审阅页或确认单。状态并入已有案例记录；自检、代检和用户接受分别写。上游空间或选型换版时标记相关机位待复核，已确认旧图留存，不扩大历史接受范围。
