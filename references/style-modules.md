# 十风格模块

每个模块规定家具、材料、配色、植物与陈设。物品、数量、门状态和机位由本案资料决定。

## 如何调用

- 只读本次所选风格的完整模块。生图任务调用模块；执行前展开正文，不临时缩写成几个风格词。
- 整理平面说明物品类别、占位与空间关系。原块的方角、扶手、桌腿与填色不指定成品。
- 模块中的品类是设计语汇，不是新增物品清单。只应用于本案存在或用户授权增加的物品。已确认的桌形、组合、功能、席位及可用空间优先。
- 家具款式、构造、材料与授权范围内的尺寸和摆放可随风格变化。不能移动墙门窗、固定设备，或侵占开门与通行空间。
- 柜体可按用途组合封闭门、玻璃门与开放展示。没有统一开放比例，也没有统一装饰件数；陈设浓度由风格与真实可用空间决定。
- 彩平只表达俯视可见面。墙体剖面、柜体图示、光源和画幅由通用母版决定；不为显示灯具或家具底框改变视角。
- 彩平确认后，效果图继承已选家具与材料。完整模块用于延续风格和补全未确定立面，不能重新随机选款。
- 模块主要描述客餐厅。卧室与厨卫按各模块的适配建议使用，并分别检查。验证范围见 [验证说明](../examples/validation.md)。
- 运行不依赖外站。研究来源仅在维护时按需读 [研究附录](../docs/style-research.md)。参考角色与限制见 [选图说明](image-references.md)。

## 风格对照

| 风格 | 主要区别 |
|---|---|
| 当代新中式 | 深胡桃细木框、米白亚麻、木作岛台与典雅茶器植物。 |
| 宋式美学 | 较浅的茶木、细格栅、木案、盆景与雅器共同成为主景。 |
| 奶油风 | 奶白与浅橡木，柔软弧面、云形茶几和不同叶型花艺。 |
| 中古风 | 焦糖油蜡皮与胡桃木框，橄榄绿、拉丝不锈钢和收藏陈设。 |
| 法式复古 | 浅线脚、深木玻璃柜、绿绒和人字木地板，斜向阳光照出收藏。 |
| 现代简约 | 宽低模块沙发、连续柜面和横向秩序，以砖红单椅形成重点。 |
| 意式极简 | 真皮低水平体量、烟熏木连续大面、精确石木细构。 |
| 意式轻奢 | 暖驼牛皮、黑金奢石、银色连续底框与古铜展示杆件。 |
| 东南亚风格 | 蜂蜜柚木、木藤与亚麻，热带叶型和丰富自然纤维陈设。 |
| 北欧风格 | 浅橡木、落地织物模块、图形毯与生活色，阳光和植物保持清爽。 |

```text
其他空间适配：客餐强调木框与案面；卧室用轻直木床头和素床品，保留现代床垫及柜门；厨卫用暖灰石砖、细木色门与普通现代洁具，不把卫生间做成古代场景。
```

```text
沙发采用连续弧背、圆钝扶手、落地内退底座与燕麦细毛绒软包；单椅采用包裹弧背，朝向服务会客关系。茶几采用不规则云形薄浅米石面与圆润浅木支撑，软硬不同；本案已确定桌形时，在该形状内表达柔和边缘。餐桌采用暖白薄面与浅木桌架，餐椅采用奶白弧壳与厚软座。岛台采用浅橡木圆角柜身、薄奶白耐水面，木侧板与浅色操作面分开，不做全石材包覆；吧凳采用圆润奶白软包与浅木框。

其他空间适配：小客厅控制扶手厚度，不挤掉坐面；卧室圆角床头不延伸覆盖床头柜；厨卫使用浅哑光砖、平板门和细石台面，保持清洁使用逻辑，不用绒面或深孔粗糙材质铺满工作区。
```

## 06 · 现代简约

[空间广角构图](photo-06-space.jpg) · [正向广角构图](photo-06-front.jpg)。只参考摄影组织，不据此改写下方固定风格模块。

```text
采用宽低模块沙发、成片柜面与水平秩序，柔灰与黑白材料形成清楚对比。避免小型普通沙发、窄竖酒柜、筒状桌腿与泛棕样板房组合；家具尺寸仍服从真实空间与舒适使用。
主沙发由可读的宽方模块组成，低直靠背、宽厚独立灰米坐垫、精确缝线与内退低底座，体量舒展而不填满通道。单椅采用砖红皮面折板形外壳与银色金属细构，朝向会客中心。茶几采用低水平浅石薄板与退入深灰支撑；边几只用于本案已有或允许增加的位置，采用轻薄小黑圆面，避免圆石鼓墩。餐桌采用薄中灰桌面与细金属交接底架，餐椅采用轻薄壳座、独立软垫与金属脚。
柜体以暖白连续通高面为主，横向宽开放段采用炭黑内衬与低层抽屉，局部木面增加温润感，不重复整列窄书格。需要融合的门齐平处理，仍保留门缝与使用功能。电视低柜采用宽水平深灰薄柜。岛台采用哑光灰柜身、薄耐水浅灰台面与退入底座，坐人侧保留真实悬挑与膝部空隙。
大块浅灰柔光砖、暖白墙与深浅大面形成清楚秩序，木材仅作温润局部。空间效果图的平顶用精确窄边与功能线光，避免满屋格栅、灯带、金线或全胡桃木。
低黑陶盘、图形艺术书、烟玻璃、雕塑与低线性马蹄莲花艺形成大小轮廓。落地植物用深绿橡皮树与哑光深灰几何盆。自然冷暖日光与材料触感支撑质感，不靠滤镜、杂乱小摆件或删物制造空旷。

其他空间适配：窄客餐压低扶手和桌缘视觉重量，保留实际舒适尺度；卧室薄框与柜门控制画面重量；厨卫同色平板、细石台面和低反光砖，不用无意义层层灯带。
```

## 07 · 意式极简

[空间广角构图](photo-07-space.jpg) · [正向广角构图](photo-07-front.jpg)。只参考摄影组织，不据此改写下方固定风格模块。

```text
低水平体量、完整材质面与精确细构形成安静关系。主沙发与单椅优先采用真皮，不用厚绒或鼓团造型。
低长主沙发采用雾褐色细腻真皮、薄平扶手、长水平坐背、清楚皮革接缝与退入底框。单椅采用深咖啡皮带曲面座背，配细金属或木构支撑，朝向会客中心。茶几采用宽低深纹石薄板与烟熏木交错基座；本案允许的边几采用轻金属细构。餐桌采用薄灰石面与精确烟木底座，餐椅采用薄皮座背与细框。桌形与数量按房间清单。
柜体采用烟熏木连续大面与相邻米灰齐平门，少量宽横向玻璃展示段嵌入大面；缝线、门与设备接口连续对齐，不碎成许多竖酒格。电视饰面在原墙内使用深灰细纹石，低柜采用长低烟木。岛台采用烟木大面、薄暗灰耐水面与内退底座，不做整块厚石瀑布造型。
石白、雾灰、烟木与深咖啡形成清楚的大面关系。艺术陈设以有体量的石雕、黑白陶器、宽浅石盘与艺术书为主，玻璃与器皿呼应生活，大小错落，并保留界面空处。
植物采用轮廓明确的龙血树与细叶兰，配炭灰柱形盆与低石盆，不在每张桌上放大树枝。真实侧光照出皮与石的微反射，照物光隐蔽，材质精确、连贯。

其他空间适配：小客厅以构造薄厚表达低重心，不扩大沙发座深；卧室双片软靠控制宽度，保留两侧通道；厨卫使用细纹石面和平板柜，在相同色域内区别墙地粗糙度，不能把水盆和设备融进背景。
```

## 08 · 意式轻奢

[空间广角构图](photo-08-space.jpg) · [正向广角构图](photo-08-front.jpg)。只参考摄影组织，不据此改写下方固定风格模块。

```text
**整体基调**

暖驼牛皮、黑金奢石与深木形成主次关系。银色拉丝金属、古铜细构和烟色玻璃提供精细层次。皮、石、木、金属的反射有明显差异，画面明亮、有层次，不做昏暗酒店氛围。

**沙发与单椅**

主沙发采用有自然细皱的暖驼牛皮和薄包边。下缘为银色拉丝金属连续低底框，底框略内退，构造清楚，不做发光踢脚。不能把银色连续底框简化成几只细腿。

单椅采用皮面、银色细杆或木金属混合框架。皮面保留真实褶皱和宽柔反射，框架与软垫分明。朝向服务会客和使用关系。

**茶几、餐桌与餐椅**

茶几采用薄黑金奢石面与银色、古铜的精细支撑构件。餐桌采用奢石薄台面与精致金属支撑。餐椅采用皮革或细腻软包，配细金属腿。桌面形状和家具组合读取本案要求，不由风格模块固定。

**柜体与展示**

电视低柜采用深木、局部奢石台面和银色收边。需要通高收纳时，与本案选择的柜体形式衔接。

餐厅展示柜采用较宽的开放展示段：黑金奢石背板、独立可辨的纤细古铜立杆、悬于杆间的玻璃或薄木层板。局部烟玻璃门与封闭收纳组合。不能只做整面空白木柜或一列窄酒格，也不能让奢石背板取代金属杆件。

展示内容包括收藏雕塑、金属器、玻璃、艺术书与陶瓷。器物形成高低、疏密和深浅层次，保留展示空隙与实际收纳用途。展示段可设置连续藏光。

**岛台与凳子**

岛台采用黑金奢石操作面、深木柜身和银色或古铜收边。台面、柜身和支撑体现不同材料，不做全石材包覆。主石纹理真切、有主次，不拼成多种奢石的混杂画面。

岛台凳采用皮座与纤细金属构造。数量、设备与操作面读取本案房间清单。

**灯具**

主灯采用纤细水平线性吊灯，柜灯采用连续藏光，呼应金属构件和柜体分层。灯具构造保持精细，不用发光家具底座替代。是否开灯及光照时段由当前制图任务决定。

**植物与花器**

观叶植物采用宽叶、旅人蕉形态；花艺采用修长蝴蝶兰。两者分别搭配深色石质柱形花盆，以及古铜或琥珀花器。通过叶型、花枝和盆器形成区别，不把同一种小叶树换个容器作为本风格植物方案。
```
