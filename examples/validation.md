# 验证范围与下一例

当前为V1.3。r4风格方向已获认可，用户在187㎡同户型实测后确认流程基本可用，并要求固定景别询问与空间约束图。下列历史检查保留原范围；不把流程认可扩大为全部图片无误或跨平台稳定。

2026-10-04，用户明确接受当前95㎡案例的十种风格、每种彩平/客厅/餐厅/主卧各一张，共40张，作为本次Skill定版基础。意式极简与法式复古彩平此前被选作质感下限；历史客餐厅17图认可中轴与近中远景表现。v1.0发布包仅携带三张有用样张，完整40张与实际生成记录留在原项目，不作为运行依赖。

已固定的是 A核实空间、B通用Prompt＋个案事实＋单一风格、C沿用本套设计并在真实空间内组织摄影，以及逐张自检和实际输入记录。用户接受一轮成果不意味着生成模型一遍必成、施工精度或跨平台输出一致。

95㎡案例的两床、六餐椅、四段挂衣区、蹲便位置、约80%封闭柜、2.7m补全墙高及相机坐标不进入通用默认值。包内样图展示的是该案例，不是新户型的空间模板。

## 下个CAD的实测方式

选一个和本例不同的户型：确认目标方案/单位/疑点 → A整理并对照原件 → 一个风格彩平 → 一个能看见邻室开口的摄影主图。先检查布局与款式传递，再扩展风格和房间。记录失败处属于识别、资料冲突、参考带入、家具选型、摄影遮挡还是质感退步，只修复被实际错误证明有必要的规则。

`synthetic-scene.json` 是人工构造的匿名数据，用于检查通用脚本，不是由新客户CAD成功提取的案例。包内工具测试与独立任务演练不等同于跨户型或豆包/Kimi/Work Buddy真实出图验收。
