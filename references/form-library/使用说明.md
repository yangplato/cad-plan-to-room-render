# 随包室内设计造型库

打开本目录的 [index.html](index.html)。完整Skill ZIP包含63条造型、46个来源及视觉观察文字、分类、检索工具和浏览页。这是独立知识库的发布快照；默认无需下载别的库或配置路径。

## 浏览与选型

按构件类别、中文/英文名称、视觉特征、风格建议和空间筛选。点卡片看特征、相似形式区别、组合建议、逐图观察和原始出处。加入选型后可导出JSON。风格标签是编辑适用建议，形式与风格分别分类。

文字及检索离线可用。照片和出处仍由原站在线提供；中国大陆可达性受线路、地区、站点及图片CDN影响。网页能打开不代表图片能加载，打不开也不能仅凭一次超时判定必须VPN。图片失败时仍可看观察文字及出处；根据已有观察选型，不把本轮未打开原图写成已经看图。

本次对照17CE中国大陆HTTP节点的8个库内链接样本：ArchDaily与gooood网页及各自图片CDN有电信、联通、移动完整200响应；Archinect项目页样本返回403，其照片CDN有200；Colombo有200与超时并存。仅代表2026-10-12的样本，不保证全库或永久可用，不由403推定必须VPN。

优先选择适合本房尺度、功能和结构的形式。同样适用时再优先实际可访问的来源。图片只是参考构件特征；本案空间由原平面和空间约束图确定。

## AI检索

推荐Python 3.10及以上，使用标准库，无新依赖。从Skill根目录运行：

```sh
python3 scripts/form_library.py search --category 吊顶 --room 客厅 --limit 5
python3 scripts/form_library.py search "悬浮" --category ceiling
python3 scripts/form_library.py show FORM_ID
python3 scripts/form_library.py select FORM_ID --room 客厅 --style 中古风
python3 scripts/form_library.py stats
python3 scripts/form_library.py validate
```

把FORM_ID替换为真实检索ID；select可接受多个ID，候选选型不自动等于用户确认。无代码工具时可直接读 [data/library.json](data/library.json) 或浏览页，选型及实际使用方式并入已有案例记录。

定位顺序：显式INTERIOR_FORM_LIBRARY_ROOT → 原项目同级独立库（若存在）→ 本目录内置快照。显式配置错误会失败，不静默换库。外部维护主版本与发布快照不双向自动同步。

## 维护

完整数据保留在 [library.json](data/library.json)，类别与别名在 [taxonomy.json](data/taxonomy.json)，字段说明在 [schema](data/library.schema.json)。

从本造型库目录可运行 python3 辅助资料/formlib.py build 重建浏览页。模板位于辅助资料/viewer.template.html，随包保留。只在需要扩充时使用既有import接口：先预览候选JSON，核实出处和视觉特征后才显式--apply；覆盖已有ID需--replace-existing。工具保留验证、备份、锁与失败回滚；测试和实验只在副本执行。

检索、查看、选型、校验及网页重建不需要外部服务。维护写入import --apply沿用fcntl文件锁，当前仅适用于Mac/Linux；Windows使用浏览与检索，不把维护写入记为已经通过。
