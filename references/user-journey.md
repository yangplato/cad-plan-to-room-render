# 用户引导与逐步确认

流程为 **01 原始资料 → 02 整理平面 → 03 彩平 → 04 空间效果图**。先交实际成果，再请用户确认。正常回应只需成果、简短检查和一个当前问题。

所有审阅和确认都在当前对话中完成。直接展示图片和完整提示词，用户可回复通过、修改意见或附标记图片。不要求固定口令、填写表单或打开外部页面；不为确认另建任何文件。

## 用户怎样开始

| 输入 | Agent 先做什么 |
|---|---|
| 只 @Skill | 介绍四步与阶段确认，问现有资料是什么，不直接生图。 |
| 只咨询 | 回答当前问题，说明实际能力，不把咨询当成制作授权。 |
| CAD | 检查可读性与多方案，展示目标原图。不能读取时说明需要 PNG、PDF 或 DXF。 |
| 图片／PDF | 检查完整性与可辨识程度，展示目标平面。没有可靠尺寸时按比例处理。 |
| 已确认整理图／彩平 | 核对用途、版本与已有确认，承接后续。 |
| 多张不同用途的图 | 先分类为本案布局、风格、质感或已选设计；有影响的歧义才询问。 |

不让用户填写技术配置。不在上传时一次问完所有材质、设备和镜头。

## 01 · 原始资料

展示目标方案的真实预览。简述已读出的房间与主要物品。多方案时先确认使用哪套。

问看不懂的设计含义，不把能自行检查的工作交给用户。例如：某矩形是柜体还是井体，某开口是门、窗还是栏杆。没有疑点时只需确认目标方案。

示例：“这是本次目标平面。请确认使用这一套；我会保留布局，整理成可辨认的底图。”

## 02 · 整理平面与疑点确认

在对话中直接展示完整整理图，不只给文字或藏在折叠说明中。只给房间编号，同名房间可加 A、B；不再编号房间内的家具、柜体或功能区。

按房间写简短物品说明。疑点用“房间号＋物品名＋局部图”定位，一次优先问一个。用户能按房间指出修改，不需要理解 CAD 编号。

示例：“02 厨房：这处门应采用推拉门还是平开门？局部图已放在下面。”

只询问会影响后续表达、且无法从资料确定的内容。例如窗是落地窗还是普通窗，栏杆高度，门的类型与开闭状态，柜体用途和电视柜形式。已有确认继续使用。可合理补全的普通装饰、器皿和纹理，不逐件询问。

整理图承担信息地图作用：说明哪里是什么物品、占用什么空间。它不指定成品家具形状。检查原布局后，请用户确认当前整理图；随后选择风格。

## 03 · 彩平

生成前在对话中展示：

- 本次实际整理平面与所选风格参考图。
- 各图角色与所用版本。
- 完整展开的生图提示词，可直接复制或编辑。

提示词分为整体要求、各房间物品与布置、风格要求。前者调用固定母版，风格层调用完整 r4 模块。不能只显示模块名，却把另一段简写发送给模型。

示例：“这是本次两张输入图与完整提示词。图1确定房间和布置，图2提供当前风格与质感。确认后我生成彩平。”

生成后先按房间自检，再交实际彩平。写清仍有的问题，不用“已核对”代替检查。用户确认当前风格、选型和图的版本后，进入效果图。

只说“喜欢这个风格”通常是方向认可，不自动表示布局通过；看明确指代，实质不清时只澄清这一项。

## 04 · 空间效果图

先确认用户想看什么。没有明确景别时必须询问：

“本空间先看广角展示整体、近景表现氛围与细节，还是两者组合？我建议〔根据本房间给建议〕。”

大客餐厅可建议广角与近景组合；小房间的整体图应读出床、窗、柜或通道。广角交代真实空间，不把房间拉大；近景表达材料与生活细节，不代替空间主图。用户已指定“2张广角＋2张细节”等安排时直接记录，不再问同一问题。

确认景别后，选真实可站立机位，并制作该机位的空间约束图。对照已确认整理平面检查墙门窗、固定结构、家具占位、邻室和遮挡。只给房间编号，不扩展内部对象编号。

首次制作每个机位前，在对话中直接展示对应约束图、其他实际输入和完整提示词，收到确认后生成。约束图必须实际传入生图工具。没有该机位的图，不能把文字镜头说明当成已完成空间约束。

已确认彩平决定本套家具与材料；完整风格模块延续风格，不重新选款。更换机位或明显改变视线时，先更新并核对约束图；同一机位的材质或小物纠错可以复用已核对图。

出图后分别检查布局、使用与摄影质感，再请用户确认该图或已约定批次。已授权的房间清单继续使用，不重复询问。

## 确认与修改

- 用户确认绑定当前成果版本、风格或机位。自检通过与用户接受分别记录。
- “做全流程”默认保留阶段与首次提示词确认。用户明确委托跳过哪些节点时按范围继续，记为委托自检。
- 提问后不进入依赖该回答的工作。沉默、超时、预选项和工具成功都不算确认。
- 同一方案漏画或错画由 Agent 按已有授权自行修正。重试的新提示词与实际输入保留供核对，不默认每次重试都让用户审批。
- 用户明确要求审核每次重试时，遵从该要求。更换风格、主要设计或实质范围也重新确认。
- 改上游版本后，相关下游改为待复核。只改一套风格，不重做其他已确认风格。
- 中断恢复时先说明停在哪步、哪版待确认，并展示该成果，不让用户重填需求。

## 对话中的审阅

在当前对话直接显示整理平面。每个风格将彩平与效果图分组展示，说明当前版本、简短检查结论和一项需要确认的内容。完整提示词用可复制的文本展示，不能只给文件链接。图片较多时按已约定批次展示，不转到单独审阅页。

以本轮展示的成果和用户回复确定确认范围。反馈和确认留在对话中，不另建确认文件。文字使用短句，写具体对象与动作；原始请求保留原文，不为简化汇报改写证据。
