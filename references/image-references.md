# 参考图使用与来源

本包三张图片为本项目生成并经用户认可的样张。它们随包提供，运行时仍须通过当前工具支持的机制实际传图。其他户型只参考相应的质感/摄影，不继承其墙门、家具数量、款式或材料选择。无需一次输入全部三张。

| 文件 | 作用 | 边界 |
|---|---|---|
| [意式极简彩平](quality-italian.png) | 软包体积、床品起伏、木石尺度、窗光与室内明暗 | 不固定新方案的意式家具、地面与配色 |
| [法式复古彩平](quality-french.png) | 细木框与织物分层、人字拼纹理、不同材料反射 | 不把其他风格都画成人字拼与法式家具 |
| [客餐厅摄影](photography-living.png) | 近中远景、材质与自然光的摄影层次 | 新户型不复制本图机位、门墙及遮挡 |

图片职责按本次实际附件填写：结构图管空间，质量样张管材质与光，风格参考管选型，本套已核验方案管跨视角连续性。若参考反复带入错误，减少参考或提取摄影要点为文字，保留结构输入优先。

相近百分比是用户审美目标，不是已计算的相似度。样张也不是逐物件尺寸正确的工程图；接受其视觉基线不免除新图核验。
