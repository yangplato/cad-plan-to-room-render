# 04 · 简模约束与 AI 表现

目标是准确、完整、美观地表达已有方案，用于风格判断、方案调整和空间沟通。不是施工图复现。默认流程：**整理平面核对 → 本房设计与共同场景 → 各机位约束图 → 主视角 → 回写共同场景 → 其他视角 → 顺序检查**。

已有确认成果直接承接。用户明确委托完成本轮设计和生成时，按授权推进，不重复等待；自检不等于用户接受。交互见[用户引导](user-journey.md)。

## 设计权限与方案确定

原平面是空间与功能依据。墙门窗、固定设备、已确认的功能分区和使用关系不能改变。整理阶段如实记录源图；设计阶段另外记录调整。

未被用户明确锁定的活动家具数量、款式和局部摆放，可由Agent在空间尺度、通行、操作和使用需求允许的范围内合理调整。不能仅因平面画两把椅子便强制两把，也不能仅因成图多于两把就判错。应先决定餐桌与座椅组合是否合理，再检查所有视角是否表达同一组合。这个原则适用于全部活动家具，不是餐椅例外。

在现有案例记录中形成一套共同场景配置：

- 来源版本；不可改变的结构、设备、功能关系；用户明确锁定项。
- 设计调整及理由；主要家具与构件的实际数量、位置、朝向、组合、尺寸依据和主要款式。
- 包括主图未入镜的相关物件，以及吊顶、灯具、柜体、饰面和相邻区域。
- 场景版本、共用简模、各机位、主图和受影响输出的对应关系。内部可用对象名定位，不要求在图面编号。

方案确定包括用户确认，或明确委托下的Agent设计决定。两者状态分开记录。此后同方案、同风格的所有视角必须共用这一配置。可见数量可以不同，但应能由真实遮挡和取景解释。不得为凑齐数量移动物件，不得逐机位独立增加、删除或重选主要家具。修改方案先改共同配置，标记并复核受影响视角。

## 制作与检查空间约束图

以整理后平面核对简模，不以彩平反推几何。CAD项目说明整理图的提取来源；图片项目不冒称CAD精度。先检查俯视投影或叠合，再检查透视图。分别记录源图不符、设计调整和未知尺寸，不能用笼统“核对通过”覆盖全部。

生成约束图前，确定关键物件的功能与基本形体。优先复用已核实的模型；只补影响识别、使用和遮挡的必要形体，不做全品类精细资产库。

- 墙门窗、柱梁、固定柜体范围、门头、设备、通道与开口保持真实；不为取景删墙。
- 家具不能只留下容易误读的盒子。坐面、靠背、支撑和独立边几要有可辨关系。双面沙发应表达两侧坐面、共同靠背和各侧使用空间，不变成靠背墙或两套无关沙发。
- 厨房区分下柜、水平台面、独立岛台和实际可见器具。检查台面连续、器具朝向与操作区域，不能把厨房变成装饰柜。器具不可为入镜移位；合理遮挡不算漏画。
- 材质、纹理、褶皱和小装饰留给AI。简模色块不指定最终配色。家具基本形体应符合已选款式，不能一边建厚直角墩，一边只靠文字要求纤细家具。
- 未定吊顶可用平顶占位。已有设计继续沿用；主图确定后，影响后续形体、数量或遮挡的设计补回同一简模。
- 检查开门、走动、座椅使用与操作间距。尺寸不可靠时标为比例核对或设计假设，不声称工程验证。

## 机位说明任务

每个机位写明“这张图说明什么”，并列出主要可见关系、合理遮挡和裁切。两机位共同说明主要空间、主要家具组合和使用关系，不要求每张塞入所有物件。

相机在可站立区域，保持可信透视和竖线。允许前景家具或辅助物件合理裁切，但不能让整组都无法读出主要家具形体、厨房功能或关键通道。需要补充说明时先调整机位和取景，不移动物件凑画面。

所有机位从同一简模输出。显著更换相机或改变可见关系时更新约束图。没有三维能力时说明未验证三维投影，不用文字清单冒充约束图。

## 参考选型与风格提取

按[造型库方法](form-library.md)选择与尺度、功能、结构相容的构件。既有选型继续承接。客厅未定吊顶默认边吊或整面退让悬浮平顶；卧室平顶或局部边吊，不混成多块浮岛。

本房要求写清对象、位置、范围与连接。灯光按照明对象确定灯型、实际数量、位置与安装方式。设计阶段可调整；方案确定后各视角沿用同一布置，不因未被用户逐个指定便允许每张随机改灯。

阅读所选风格模块，但不原样复制。只提取本案实际物件适用的材料、配色、构造与陈设要求。删除与共同配置冲突的数量、造型、用途和未传附件引用。例如双面沙发不复制单面连续弧背要求；没有吧凳就不加入吧凳段。保留原模块路径、采用与排除的条款及完整实际提示词。

彩平继续提供材料与风格参考，不作为简模布局核对依据。可以实际传图并注明职责，也可以提取已确认材料为文字并记录原因。不能根据少量试验规定全局删去彩平或整理图。外部照片是否查看、是否传入均如实记录。

## 实际提示词与输入

在当前对话展示真实输入和完整实际提示词。仅给真实附件编号，不引用未传图像。主视角必须传当前约束图；后续视角必须传自己的约束图与已选主图。彩平按本次用途选用，不从彩平推断机位或改变固定布局。

```text
生成〔方案/风格/房间/机位〕的单张写实效果图，画幅〔实际画幅〕。
实际附件：图1为当前场景版本的本机位约束图，提供结构、形体、相机和遮挡；〔真实传入时列图2彩平，材料与风格参考，不提供布局变更〕；〔后续机位列已选主图，仅继承同一方案款式、材料与设计，不复制主图机位〕。
空间与功能：〔不可改变的墙门窗、固定设备、功能分区与使用关系〕。
共同场景：〔已确定的主要物件数量、位置、朝向、组合和基本款式，含相关镜头外物件〕。保持同一个实际场景；不为显示所有数量移动物件，不独立增删。遮挡物件无需强行画出。
本房设计：〔吊顶、照明、柜体、台面、岛台、饰面与连接〕。保留功能形体，完善边缘、材料和软装细节，不机械复制粗块，不重新布局。
本机位任务：〔主体、主要关系、前中后景、合理裁切和遮挡〕。不以整组全部物件必须在本张可见为目标。
有效风格要求：〔从模块提取的本案条款，已清除冲突数量、造型和虚假附件引用〕。
自然竖线，可信透视，真实材质和光影，完整、美观、有氛围。只输出一张摄影图，无文字、水印或拼图。
```

## 主视角与其他视角

主图经用户确认或委托代检选定后，检查它是否补全了影响其他机位的主要形体、位置或遮挡。若有，先将合理且获授权的补全写回共同配置和简模，再重出受影响约束图；若违反固定边界，修正主图，不能倒改墙门窗迎合错误图像。

主图没有入镜的物件从共同配置读取，不能凭主图推定全场景。后续机位使用自己的有效约束图和已选主图。共同配置决定实际数量与布局，主图提供已选设计外观。不同角度显示不同数量时，依据同一模型说明遮挡或裁切，不强行补画。

后续更改主要设计，更新共同配置与版本并复核全部受影响角度。未指定木纹、褶皱、小摆件可不同；主要沙发类型、柜体组合、灯具布置不能每角度另选。

## 自检、修正与停止

按以下顺序检查，前项问题不能被氛围抵消：

1. **空间与功能**：结构、固定设备、分区、通行、操作和使用关系；应可见的功能是否遗漏。
2. **主要物件合理性**：坐面与靠背、桌椅组合、台面与器具等是否可信、完整、可用。
3. **同方案一致性**：各视角能否由共同配置解释；主要物件实际数量、位置、朝向、组合和款式是否一致。看不见不算通过，也不算自动缺失。
4. **视觉表现**：风格、构图、材料、光影和整体完成度。

数量以已确定场景为依据，不以原平面符号数或某一张可见数量为依据。设计阶段合理改变席位不算错误；方案确定后机位独立增删、漂移物件属于一致性问题。未指定纹理、褶皱、柜门细分和小装饰不反复修图。

问题先定位最早出错步骤：来源识别 → 设计配置 → 简模 → 相机与约束图 → 输入与提示词 → 生成。上游错误先修上游，更新依赖输入，再生成；不能靠反复追加否定句掩盖错误体块、冲突模板或缺失器具。

同一方案、同一机位首图后的累计必要修正最多两轮。上游修正导致该机位重生成也计入，不因换文件或请求重置。达到目的即停；达到上限仍有问题，展示较完整版本与残留问题，不标通过。新方案须有实际设计变更与授权，不能改名规避上限。用户说停止立即停止。

结果并入已有案例记录。保留首图、失败图、实际输入、提示词、修改步骤、通过项和残留问题。自检、委托代检与用户接受分别记录；不把单次两机位结果写成跨户型稳定性证明。
