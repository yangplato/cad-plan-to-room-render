# 历史彩平质量对照

本文件记录2026-10-04的有参考图和无参考图试验。历史结果用于说明方法的收益和限制，不作为当前任务的执行模板。

当前任务按 [彩平母版](color-plan.md)、完整 [风格模块](style-modules.md) 和 [参考说明](image-references.md) 执行。

## 2026-10-04 的实际对照

- 固定同一整理平面、同一1.1母版、同一个案事实、同一生成工具。选择意式极简和中古风，各做两种方法，每种独立生成两次，共8张。
- T：整理平面＋完整文字。R：相同输入，再实际上传包内意式极简质量样张，并说明它只管质感。意式是同风格参考，中古是跨风格参考。
- 唯一有意改变的是是否输入质量图及与之对应的角色说明。没有固定种子，工具不暴露底层模型版本/采样参数，不能把独立重复称作同种子严格配对。
- 8次首次输出全部保留，没有择优替换；母版和两个风格块在8次调用中冻结。随后另做2次针对性修正，单独记录。
- 主执行者逐图看图；另一个不知道T/R分组的评审按乱序A–H独立观察。结论是定性比较，不是客观“90%相似度”、用户新验收或统计显著性证明。

| 首轮图 | 与既有样张的质感比较 | 具体发现 |
|---|---|---|
| 意式 T1 | 仍偏平 | 床面较规整，光影较浅；双椅之间多出小桌。 |
| 意式 T2 | 仍偏平 | 床品体积不足，单椅偏方；户型外投影明显。 |
| 意式 R1 | 较接近 | 被面起伏、软包和方向窗光接近基线；蹲便的长轴/排水端不够可信。 |
| 意式 R2 | 较接近 | 床品和光照层次较完整；石纹偏繁，蹲便仍趋于方盘圆槽。 |
| 中古 T1 | 仍偏平 | 木框、独立坐背和餐椅构造更明确，布料偏平、外投影重。 |
| 中古 T2 | 仍偏平 | 有中古木构语汇；茶几从矩形变椭圆，原绿植被误作脚凳。 |
| 中古 R1 | 较接近 | 软包和床褶改善；意式皮桶椅、局部石地面和额外小几被带入。 |
| 中古 R2 | 较接近 | 质感改善，但主要座椅沿用旧式样过多；蹲便与版面仍需修正。 |

这8张中，4张R图均被匿名评审归为“较接近基线”，4张T图均为“仍偏平”；这只是8张的观察结果，不能外推成100%成功率。全部首轮图顶部留白不足，部分有外投影；没有一张被标记为整体交付通过。布局仅作可见关系检查，没有用像素相似度冒充逐墙逐洞核验。

两次后续修正保住了大部分床品和光照，却没有可靠纠正蹲便方向、约12%上下留白；中古座椅也没有充分改变。**“先生成再用一段话纠正”并非已经验证可靠的兜底。**此处停止扩展效果图并保留失败，不把它们更新为默认质量样张。

完整首次输出、修正图、实际Prompt与输入角色保存在[v1.1.0 Release](https://github.com/yangplato/cad-plan-to-room-render/releases/tag/v1.1.0)的独立 `quality-evaluation-v1.1.0.zip` 中；解压打开 `审阅.html`。不需要下载证据包才能运行Skill，主包保持轻量。

## 换平台、模型或户型

先选一个代表性彩平试制。需要比较输入方法时，使用同一底图和文字，分别生成有参考图与无参考图的小样。检查材质、光影、风格和空间是否正确，再决定是否扩大数量。

上述试验只覆盖一个户型、两种风格和同一生成工具。它不能证明新户型不会复制参考布局，也不能证明其他平台能得到相同质量。
