# 01–02 · 原始资料识别与平面整理

本文件覆盖 `01-source` 与 `02-clean-plan`，它们是两个独立成果确认点。先按 [用户引导](user-journey.md) 判断入口；收到资料就先检查，只有咨询时不启动制作。确认记录绑定具体成果版本，不用一条“已核对”覆盖两步。

## 输入路线

- DWG/DXF：确认目标方案（同一图可能有多套）、单位、图层、块、外参及文字。能读 DXF 时可用只读清单工具辅助识别；DWG 只在已具备合适转换器时转换副本。不能解析则请求导出 PNG/PDF/DXF，不把截图当原生几何。
- PNG/JPEG/PDF：检查是否完整、文字与设备是否可辨，PDF 实际渲染后看图。没有可靠尺寸时用像素／比例记录，不凭总面积反推每条墙长。
- 已确认整理平面：核查与当前原件版本一致后复用，不重复清理或让模型再设计。

原件另存保留，不覆盖。若资料有多套方案又未指定，先给可视定位让用户选定，不默认为面积相近者。原生几何转换时记录文件哈希、原点、单位、轴向、旋转与范围；所有对象沿用同一坐标变换，避免房间间漂移。

转换返回成功不代表无损。记录缺失对象、块、填充及文字警告，并实际看导出的线图；空白、缺线、错误填充和拉伸先排查转换与显示，不把它们写成原图事实。局部裁图必须沿用源坐标和等比变换，检查实际可见内容；CAD单位未指定时保留原单位并请求确认，不自动标为毫米。多楼层分别记录，不能将一层的确认扩到另一层。

显示遮罩（如WIPEOUT）须按背景色表达并保留遮罩几何。黑白显示策略可能把它绘成黑块；先核对显示及块内轮廓，不把黑块直接当墙，也不全局删除遮罩来找家具。

## 识别与最小澄清

根据轮廓、文字、尺寸、块属性与空间上下文综合判断，不能仅按图层名或最近家具库类别分类。记录墙/门/窗、主要家具、柜体、洁具、电器；原图块的细分线通常不等于产品构造。

一个简短个案表即可：对象或位置、类别、数量/朝向、依据、确认状态。蹲便或坐便、门或开放通道、柜或墙、柜体用途、阳台机位等会影响空间的疑点先确认。描述位置要让用户能找到；必要时在原图副本标号。标注用于识别，最终干净底图另存无标注版。用户确认与图纸实质冲突时指出冲突，不悄悄择一。

图示库仅用于把已确认对象表达清楚，不能反向决定原图是什么。不强求把所有可移动小物建成 JSON。

用户分多条回复时合并读取：按编号的补充与按顺序的答复分别对应，不逐条回复重置问题清单。结合原问题与内容核对；编号笔误能唯一定位时说明对应，不能唯一定位或答复有冲突时才追问。保留原话和对应问题；“一般为毫米”等带条件说明记录为工作依据，不写成原生单位已核实。用户要求将原符号改成另一类型时记录为用户指定。

“马桶”等宽泛名称不能直接等同于坐便。类型未明确且影响图示时，给出蹲便、坐便等具体选项。用户后来明确类型或方向时，以最新明确答复更新当前事实；保留原话与旧解释，将旧解释标为已覆盖。同步修正图示、数量和确认版本，不重复询问已明确的信息。新的疑点答复仍不等于整图确认。

用户指定更换洁具类型后，复核安装方向与占位。只说“改坐便”不确定水箱方向；不能用原蹲便图标代答。核对稿可保留源占位并标问，注明尚未定向；答复后更新实际图示，取得整图确认再进入彩平。

### 01 成果确认

展示目标原图的实际预览和简短识别摘要，必要时标出疑点，不能仅回复“文件收到”。让用户确认目标方案和当前识别结果；关键疑点解决后，再进入02。多方案选择不自动等于全部识别信息已确认。没有疑点时只需确认目标方案，不编造问题。

用户已明确提供确认过的资料可承接；“做全流程”“统一测试”和文件名“定稿”不取消该节点。无法确定的空间事实必须问用户；Agent 不可代答。等待答复时可制作保留原坐标和源线的定位草图，但不能把未知符号补成确定物件。

## 干净底图的默认表达

保留墙体真实轮廓与厚度、洞口和主要物件的类别、方向及占地。尺寸、文字、人物、门开启弧与柜内 X 线用于理解后移除；不能把开门弧变墙，也不能连清洁具实体。保留原门洞；方向未确认时简洁门框即可。

- 墙用统一可辨的剖切表达，不因 CAD 黑白填充赋予不同外观。
- 已确认挂衣柜：连续柜腔、外框、原分区，一条细挂杆加垂直成排短线。横竖柜旋转同一图示。它表示挂衣功能，不是逐件真实衣架、百叶、格栅或叠衣格；不强行解释为统一1.6m剖切。未确认柜体不套此图示。
- 低柜和工作台显示可见的完整水平面；不把辅助内框变凸起围边、空格、装饰门板。
- 洗衣机未定机型用简洁水平平顶；前开门圆形滚筒在竖直正面，不能画在顶面。明确上开门型号才表现盖板。
- 蹲便器、坐便器、浴缸、淋浴分别表达，保持安装方向；不要用常见配置替换。

## 核对与输出

把整理图和原件同朝向、同比例叠看：先外轮廓与墙门，再连通和物件。结构化时将 JSON 回绘到原 CAD 坐标，与独立读取的原始线条比较；意思是“把识别结果画回去检查”，不是检查 JSON 语法就算正确。碰撞或图示公差留实，不为了消除警告偷偷移家具、缩墙。

输出干净平面＋简短本图确认信息。原生工具能可靠输出时优先确定性绘图；使用生图清理也必须回查，生图不是无损CAD转换。

### 02 成果确认与交接

整理平面同时是后续制作的空间约束图。展示原件与真实底图的同朝向、等比对照，附主要变化及自检结论，请用户确认该版本的墙门窗、连通、主要物件及占位。疑点答复和整图确认分别记录。可以同时收集风格偏好，但只回答风格名称不等于确认底图；未获用户对当前02版本的确认，不生成03彩平，包括批量测试和局部风格诊断。未能生成底图就说明能力缺项，不把文字清单当作完成。

每套用位置编号列出疑点，例如“客卫左上虚线方框”“儿童房/健身房叠画”；附局部预览及可辨选项。没有可靠尺寸时标明比例依据，不能以床图标或阈值包络推算精确墙长。主要床、桌椅、沙发、坐便和台盆逐项记录数量、朝向；不可仅检查房间总数。已发现的比例或设备错误先修正，不能交给用户替 Agent 验错。

03继承这张被确认的底图及个案事实，原件继续保留为核对依据。结构或识别信息修正后更新版本，相关下游标为待复核；不沿用旧版本的通过结论。确认与版本记录见 [运行记录](run-record.md)。
